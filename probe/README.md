# 可执行性探针（不是实现）

这个目录**不是产品代码**，也不进入实现阶段。它只做一件事：

> 把 `docs/` 里的设计**当成假设**，用最小代价去问：**它建得起来吗？约束真的会拦人吗？**

后续计划：结构化设计 → 面向对象设计（详细设计）→ 审核 → 实现。本目录在此之前只回答"设计是否可执行"。

## 怎么跑

```bash
python3 probe/run.py
```

输出每项 `PASS / FAIL / GAP`（本轮 G1–G5 已定后，GAP 归零）：

| 标记 | 含义 |
|---|---|
| `PASS` | 设计假设在 SQLite 上成立 |
| `FAIL` | 设计假设**建不起来或拦不住**——设计需要改 |
| `GAP` | 数据库无法表达，只能由应用层/判据保证——**这一项必须写进设计并配判据** |
