# 项目基线：质量与风险

> 本文件是项目级质量基线：记录质量属性取舍与主要风险；不记录某一次运行结果。改动本文件属于项目级基线变更（M8-2 之后走追加签）。

## 质量属性

- 可审计性：状态与判定都能在文本中追溯（事件/台账/签字/读数），脚本不维护不可见的第二状态。
- 可复跑性：门禁与读数给命令和真实输出；同一工作树重跑得到同一 verdict（时间/随机字段除外）。
- 可移植性：零运行时依赖（Node 标准库），不依赖数据库或常驻服务；归档目录可整体搬走。
- 可恢复性：索引可从正文重建；归档可 restore；追加只增不改，历史可由 git 反查。

## 风险登记

| 风险 | 影响 | 处置 |
|---|---|---|
| 索引与正文分叉（手改正文不 reindex） | 未决项显示错误、审计漏项 | `check` 校验 sha256/卷头/`index_stale`；`reindex` 重建；`--deep` 审计 |
| 大台账单卷全 open | `add`/`view` 超预算（D-95） | 活跃卷 >1000 行或里程碑收口必须 `rotate`；`check` 对 >5000 行 WARN |
| 文本层可伪造（正文+索引+哈希一起改） | 机检可能一致通过 | 不宣称防伪造；历史真伪以 git 追加历史为准，审计用 `--deep`，高风险走人签 |
| 多会话并发写 | 冲突/丢失更新 | 卡 hold、锁表、append-only 冲突行与显式 409 语义；调用方按冲突处理 |
| 检查器自身规则漏洞 | 假绿 | 每条规则要求可红变异；检查器改动走 review；读数门复跑 |
