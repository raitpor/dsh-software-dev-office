# 项目基线：测试策略

> 本文件是项目级测试基线：定义不同变更类型用什么测试技术证明，不记录某一次运行结果。改动本文件属于项目级基线变更（M8-2 之后走追加签）。

| 变更类型 | 测试技术 |
|---|---|
| 检查器规则/脚本逻辑 | `node --test` 单测覆盖边界；`/tmp` 副本夹具跑正例 + 反例 + 变异红证（`expected=red actual=red restored=green`） |
| 模板/文档/流程文本 | `check.mjs` 结构与引用校验 + `grep` 断言；`/tmp` 副本删段/改字段反例，确认会红 |
| 基线/计划/冻结段 | `--plan` 重算 hash + `baseline_drift` 反例；追加签副本验证“改冻结段必须重签” |
| 台账/索引/归档 | `ledger.mjs` 副本夹具（卷头/索引/open 双向）+ `check --deep` 审计；篡改字节与删条目反例 |
| 发布前整体 | 全量 `check`、`--trace`、`--plan --milestone M<n>`、`gate.mjs`、读数门；`/tmp` 干净副本复跑读数 |

约定：测试引用必须能落到可复跑命令或允许目录的 `文件:行`；只写“已验证”不算证据（M8-1 C7）。
