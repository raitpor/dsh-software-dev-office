# 项目基线：需求

> 本文件是项目级需求基线：每条需求有稳定 id 与可判验收口径；卡面用 `references:` 引用，不复制正文。改动本文件属于项目级基线变更（M8-2 之后走追加签）。

### R-01 流程状态全部落文本
- 验收口径：存档目录内不含数据库/二进制状态文件；`node skills/sdo-flow/scripts/view.mjs state` 能仅凭 `.sdo/` 下的 Markdown 与 JSON 索引重建当前里程碑、卡、台账、签字与读数。

### R-02 门禁与读数可被人复跑
- 验收口径：每份读数条目都给出一条可执行命令与真实输出摘要；对同一工作树重跑该命令得到相同 verdict（时间/随机字段除外）。

### R-03 签字由人类发起且可追溯
- 验收口径：每个 `.sdo/sign/S*.md` 都含「被签对象、选项、时间」三项且通过 `check.mjs` 的签字段校验；`.sdo/计划.md`/里程碑状态引用的签字编号都能在 `.sdo/sign/` 找到对应文件。
- 不保证：签署者身份（agent 可直接写签文件）；身份只靠人签与评审确认。
