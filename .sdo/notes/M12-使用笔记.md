# M12 使用笔记：摩擦与结论

> 本文件只记本里程碑（M12）真实发生过的摩擦；每条给“现象 / 复跑命令 / 结论”。

## 1. `readings.mjs init` 骨架里的 R55 达标线命令与当前 refs02 标题不一致

- 现象：M12.1 的 R55④ 写 `awk "/^### 判据说明表/,/^## /"`，但 `references/02-判据与门禁.md` 的标题已改为 `## 8.1 判据说明表（由 criteria-doc --emit 生成）`；照抄命令得到空块，`diff` 把整张表报成缺失（46 行 vs 0 行）。
- 复跑命令：`diff <(node skills/sdo-flow/scripts/lib/criteria-doc.mjs --emit) <(awk '/^### 判据说明表/,/^## /' skills/sdo-flow/references/02-判据与门禁.md) | wc -l`
- 结论：改用表头块提取（`awk '/^\| 判据 id \|/{f=1} f{ if (substr($0,1,1)!="|") exit; print }'`）后 `diff` 为空；读数 R55 已按实际命令记录，并注明“标题在 M11-12 改过”。建议 M11-12 同步更新 M12.1 的度量命令（本卡不改归档里程碑）。

## 2. R57 的“check --deep 0 警”在真实树不可达（D-204 历史行）

- 现象：`view state` 修后已不再报“表列数不齐”（0 次），但 `check --deep` 在真实树仍是 0 错 **1 警**——该警来自 `.sdo/台账.md:207` 的 D-204 历史行（6<7），按 D-204 explain 刻意保留、要求“历史行不改；追加 explain 留痕”。
- 复跑命令：`node skills/sdo-flow/scripts/view.mjs state 2>&1 | grep -c '表列数不齐'; node skills/sdo-flow/scripts/check.mjs --deep 2>&1 | tail -1`
- 结论：视图口径不一致本身已消除；R57 如实判 **partial**（②的“0 警”未达），不把 D-204 设计例外改口径成 pass。建议未来在 M12.1 的达标线把“0 警”限定为“无 `表列数不齐` 类告警”，或把 D-204 降级为 info。

## 3. `gate.mjs init` 生成的 M12 门表不含“接受 partial”的第 3 节

- 现象：`gate init M12` 只生成四门 31 行，`gate.signed` 必须 partial（门签前）；若不在第 3 节写 `选项：签：接受 …`，`gate --file` exit 1（“partial 未被接受”）。
- 复跑命令：`node skills/sdo-flow/scripts/gate.mjs init M12 --check >/dev/null; node skills/sdo-flow/scripts/gate.mjs --file .sdo/gates/M12.md | tail -1`
- 结论：手填第 3 节是必要动作，模板/init 应提示；本卡已在 M12 门表第 3 节写明“gate.signed 1 项”与“readings R57 partial”两条接受。

## 4. `gate.mjs init --check` 在文件已存在时只读、不重写

- 现象：想用 `init` 重生成表时，`--check` 前后 `sha256sum` 相同、`test -f` 都为 0（存在），说明 `--check` 不会覆盖已有门表；这正好可用于 R55① 的“只读渲染”证明。
- 复跑命令：`h1=$(sha256sum .sdo/gates/M12.md | cut -d' ' -f1); node skills/sdo-flow/scripts/gate.mjs init M12 --check >/dev/null; h2=$(sha256sum .sdo/gates/M12.md | cut -d' ' -f1); echo "$h1 $h2"`
- 结论：可放心把 `--check` 写进读数命令；需要重写时另行处理（不要在读数里做）。
