# M11 冷启动任务书（R49 的固定输入）

> 用途：R49 要量“**结构性字段能不能只靠命令写**”。任务、禁令、可读范围、卡点定义必须钉死，否则每轮结论不可比。过程记录写 `.sdo/notes/M11-冷启动记录.md`。

## 1. 环境

- 空目录 `/tmp/m11-cold`，只拷 `skills/sdo-flow/`（`cp -a skills/sdo-flow /tmp/m11-cold/`）。
- 先跑 `node skills/sdo-flow/scripts/init.mjs`（M10-5 交付）。
- 禁止读本仓库的 `.sdo/`（那是“答案”）；禁止读 `skills/sdo-flow/scripts/*.mjs` 源码（读到即记一次“越界读取”）。
- 你的产物一律写在 `/tmp/m11-cold/` 内；**不要**回写本仓库。

## 2. 任务（从 0 走到待签草案）

1. **git 可选**：有 git 就 `git init && git add -A && git commit -m "init"`，签字用 `git:<sha>`；没有 git 直接用 `tree:<内容指纹>`，本步骤可跳过（`sign.mjs new` 不再要求 git）。
2. `init.mjs` 建骨架。
3. `baseline.mjs init` 建基线四份，补成可过 `check` 的成品。
4. 写意图（用 `templates/意图.md`）。
5. `milestone.mjs new M1 --topic <主题>` 建里程碑；门禁/判据用显式声明行；`milestone.mjs freeze M1` 出冻结 hash。
6. `sign.mjs new --kind 计划 --milestone M1 --scope <文本>` 生成计划签草案（`- 判定：待填`，人签部分留空）。
7. `card.mjs new M1-0 --owner <席位> --intent "<标题>" --criteria "C1:结构:…;C2:语义:…" --write-scope "<路径>"` 建卡；填判据与证据；台账 `ledger.mjs add` 若要记账。
8. `gate.mjs init M1` 生成门表骨架（若冻结段写了 `- 门禁判据：G_x = a.b, …`，只生成映射里的门）。
9. `readings.mjs init M1` 生成读数骨架。
10. `check.mjs` 跑到 0 错；`gate.mjs --file .sdo/gates/M1.md` 跑到通过（或如实记录“骨架待填判定”）。
11. `sign.mjs draft --milestone M1` 输出待签材料，到此为止（**不要**伪造人签）。

## 3. 禁令：以下结构性字段**只许命令生成，不许手写**

| # | 字段 | 唯一允许的命令 |
|---|---|---|
| 1 | 冻结段 hash（`- 冻结段 hash：`） | `check.mjs --print-frozen-hash` / `milestone.mjs freeze` |
| 2 | 签文件四要素（范围/被签对象/冻结段 hash/选项） | `sign.mjs new` |
| 3 | 签文件锚点（`- 被签对象：` 的 sha） | `sign.mjs new`（禁手抄） |
| 4 | 门表行（`| n | criterion | … |`） | `gate.mjs init`（禁手抄判据名） |
| 5 | 读数行（`## R<n>` / `## overall`） | `readings.mjs init` |
| 6 | 卡骨架（编号/视角/判据表头/证据表头/收口清单） | `card.mjs new` |
| 7 | 台账条目（编号/类型/路径/时间） | `ledger.mjs add` |
| 8 | 基线四份骨架（`templates/baseline.md` 拆分） | `baseline.mjs init` |

**例外**：命令不生成的**内容**（判据文字、主题、理由、判定值、证据命令与输出）必须手写，不算“手改”。判不清时按“命令能不能生成”二分：能生成却手抄 = 手改。

## 4. 允许读的文件

`SKILL.md` 必读；其余文件最多再读 3 个（必须是 `SKILL.md` 里点名的 reference 或模板，不得是脚本源码）。

## 5. 卡点定义（与 M10 任务书一致，可数）

**卡点** = 只读 `SKILL.md` 后**无法确定下一条该跑什么命令**：记下①当时想做什么 ②试了几次 ③最后靠哪句话/哪个文件才走下去。同一处反复试只算 1 个卡点。

**手改** = 用编辑器/`cat >`/`>>` 直接写入第 3 节表格里任一字段（含“先手写再让命令补”）。每处记 `文件:行`。

## 6. 记录格式

| # | 步骤 | 命令与 exit | 产物路径 | 卡点/手改 | 文件:行 | 靠什么走下去 |
|---|---|---|---|---|---|---|

末尾必须给：`手改总数 = n`、`卡点总数 = m`、`越界读取 = k`。

## 7. 达标线（对应 M11 的 R49）

- **手改 = 0** 且 **卡点 = 0** ⇒ R49 可判 pass。
- 任一 >0 ⇒ 记录如实记 partial，并点名“缺哪条命令/哪句话”。
- 脚本源码越界读取 = 0；额外读文件 ≤3（不含 `SKILL.md`）。
