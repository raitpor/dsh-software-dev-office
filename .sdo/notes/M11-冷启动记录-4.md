## 4. 卡点明细

### K1 · `sign.mjs new` 需要项目根自己就是 git 根
- 想做什么：按任务书第 5 步生成计划签草案。
- 试了什么：直接跑 `sign.mjs new`，exit 2；stderr：“项目根不是独立 git 仓库或没有 HEAD（项目根必须等于 git 根，不借用外层仓库）：sign new 需要被签对象 commit（先 git commit）”。
- 靠什么走下去：SKILL 第 7 步只写了“有 git 的仓库里需要可解析的 git HEAD”，没写 `sign new` 也硬性要求独立 git 根；按 stderr 在 cold4 内 `git init` + local config + `git commit` 后重跑成功。新增 `.git/` 属 cold4 内，未越界。
