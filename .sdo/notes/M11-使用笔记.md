# M11 使用笔记

> 给下一个里程碑的实操摩擦；每条：现象 → 命令 → 结论。

## 1. 副本缺 `.git` 时历史签全报 `signed_tree_unknown`

- 现象：只复制 `.sdo` + `skills` 到 `/tmp` 做夹具，`check` 对每条历史 `commit:` 签报 `signed_tree_unknown`（80 条），基线不再可信。
- 命令：`cp -a .sdo skills /tmp/x && cd /tmp/x && node skills/sdo-flow/scripts/check.mjs`
- 结论：做“正常树 0 误报”基线必须连 `.git` 一起复制（或直接用真树）；否则只能做“错误码出现”的变异夹具，不能当基线。

## 2. 已签里程碑上造 `preset：` 变异会先撞锚点

- 现象：在已签 M11 冻结段插 `preset：incremental`，`check --plan M11` 先报 `signed_anchor_mismatch`，`preset_field_removed` 不出现。
- 命令：`sed -i 's/^hash[:：]/preset：incremental\n&/' .sdo/milestones/M11.md && node skills/sdo-flow/scripts/check.mjs --plan --milestone M11`
- 结论：`preset_field_removed` 只对“新签/未签”里程碑可独立取证；已签卡要另建未签夹具（M12），否则红码被锚点噪声盖住。

## 3. `gate.mjs` 声明覆盖校验的正则 bug

- 现象：有冻结段 `判据：` 声明、但没写“按门映射”时，`gate --file` 恒报 `missing_declared_criterion`（每条声明判据各一条），即使门表每行都有。
- 命令：`node skills/sdo-flow/scripts/gate.mjs --file .sdo/gates/M11.md; echo $?`
- 结论：`gate.mjs:299` 的模板串写成了单反斜杠 `\b`（=退格字符），导致正则永不命中；修成 `\\b` 后 exit 0。M10 无声明所以没暴露，属 M11-G 才被读数逼出来的真 bug（D-261）。

## 4. 声明类/结构类红码会被“卡表无数据行”抢先

- 现象：新建 M12 后直接改声明跑 `check --plan M12`，首条报「卡表没有数据行」，声明类红码不出现。
- 命令：`milestone.mjs new M12 --topic t && … && check.mjs --plan --milestone M12`
- 结论：内容规则先于声明规则；做夹具要先补一行卡表数据（或直接拿已收口里程碑），否则以为规则没生效。

## 5. `init` 没有“缺参 exit 2”形态

- 现象：R50 要求每条命令 1 个缺参反例，但 `init.mjs` 无必填参数，`init --bogus` 仍 exit 0（未知参数被忽略）。
- 命令：`node skills/sdo-flow/scripts/init.mjs --bogus; echo $?`
- 结论：`init` 的该条按 N/A 记录，不能为了凑“每命令反例”硬造不存在的约束。
