# M10 冷启动任务书（R44 的固定输入）

> 用途：R44 要量“只靠文档能不能走通”，就必须把“任务、禁令、可读范围、卡点定义”钉死，否则每轮结论不可比。本文件是 R44 的输入，过程记录写 `.sdo/notes/M10-冷启动记录.md`。

## 1. 环境

- 空目录 `/tmp/m10-cold`，只拷 `skills/sdo-flow/`（从本仓库 `git archive` 或 `cp -a`）。
- 先跑 `node skills/sdo-flow/scripts/init.mjs`（M10-5 交付）；若该脚本还不存在，则按 `SKILL.md` 手工建 `.sdo/`。
- 禁止读本仓库的 `.sdo/`（那是“答案”）；禁止读 `skills/sdo-flow/scripts/*.mjs` 源码（读到即记一次“越界读取”）。

## 2. 任务

> 用一个 3 条需求的小项目跑完 M1：写意图 → 建基线四份 → 写里程碑（含 2 条读数与 1 张卡）→ 建卡 → 为卡 C1 采一条证据 → 跑 `check` 到 0 错 → 生成待签草案。

## 3. 允许读的文件

`SKILL.md` 必读；其余文件最多再读 3 个（必须是 `SKILL.md` 里点名的 reference 或模板，不得是脚本源码）。

## 4. 卡点定义（可数）

**卡点** = 只读 `SKILL.md` 后**无法确定下一条该跑什么命令**：记下①当时想做什么 ②试了几次 ③最后靠哪句话/哪个文件才走下去。同一处反复试只算 1 个卡点。

## 5. 记录格式

| # | 想做 | 试了什么 | 结果 | 靠什么走下去（`SKILL.md` 节号 / 文件） |
|---|---|---|---|---|

## 6. 达标线

见 `.sdo/milestones/M10.md` 的 R44：卡点 ≤2、额外读文件 ≤3（不含 SKILL）、脚本源码 0；修复后重跑一遍，卡点清零。
