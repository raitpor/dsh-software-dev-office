## 4. 未计入但值得记的观察

1. **命令重叠**：`init.mjs` 已把 `.sdo/baseline/` 四份写成成品，`baseline.mjs init` 只能跳过；§3 #8 的“唯一允许命令”实际由 `init.mjs` 代劳。
2. **草案被当签**：`sign.mjs new` 写 `- 判定：待填`（任务书说 `- 判定：待签`）；`check --plan` 对这份待填草案判 **0 漂移**，即“尚无计划签”的签前红码在 `sign.mjs new` 之后消失，签前/签后无法由 `--plan` 区分。
3. **门表重生成**：`gate.mjs init` 对已存在文件只打印“已存在，跳过”，无 `--force`；要按新声明重排只能先删生成物再 init（删的是命令产物，不是内容）。
4. **draft 的 git 锚点**：cold3 嵌套在仓库内，`sign.mjs new`/`draft` 取外层 `HEAD=1f6dc9e`，把 cold3 的相对路径与外层仓库同名 `.sdo/` 比较，报 `TREE_MISMATCH`；同时输出 `DIRTY` 却又写“工作树：干净、改动范围：无”，自相矛盾。未 `git commit`（禁止回写仓库），按要求止于 draft。
5. **计划索引不同步**：`milestone.mjs new` 索引行 `preset` 列写 `—`，里程碑内写 `preset：incremental`，没有命令同步；`check --plan` 不报。
6. **`references:` 无命令**：卡面 `references: [R-01, R-02, R-03]` 由 `card.mjs new` 不生成；按 SKILL §5.1 手写一行后 `--trace` 才 0 问题（不属 §3 八类，未计手改）。
