## 意图

用无上下文席位按任务书从 0 走到 `draft`，全程只用命令；记录每次“不得不手改”的点与文件:行。

## 判据

| 编号 | 判据 | 类型 | 反例 |
|---|---|---|---|
| C1 | 任务书写死：禁手写结构性字段清单（8 类）、“命令+exit+产物”记录格式、卡点定义（沿用 M10 任务书）、`手改>0 ⇒ R49 至多 partial` | 结构 | 删掉清单任一类 ⇒ 评审判红 |
| C2 | 记录含每一步的命令、exit、产物路径，以及手改次数与文件:行 | 结构 | 手改次数写 3 但不给文件:行 ⇒ 断言红 |
| C3 | 复跑结论：手改 0 且卡点 0 ⇒ 支持 R49 pass；否则如实记 partial 并点名缺口 | 结构 | 把有手改的一轮记成 pass ⇒ 评审判红 |

## 准入

依赖：M11-0、M11-4、M11-2、M11-3

- 前置：M11-0、M11-4、M11-2、M11-3 已收卡
- M11 计划已签。

## 证据

| 判据 | 命令与输出 | 判定 |
|---|---|---|
| C1 | exit=0; <no output>；grep -q '手改清单' .sdo/notes/M11-冷启动记录.md && grep -q '卡点清单' .sdo/notes/M11-冷启动记录.md | pass |
| C2 | exit=0; <no output>；grep -q '命令（均在项目根）' .sdo/notes/M11-冷启动记录.md && grep -q '文件:行' .sdo/notes/M11-冷启动记录.md | pass |
| C3 | exit=0; <no output>；grep -q '手改清单' .sdo/notes/M11-冷启动记录.md && grep -q '文件:行' .sdo/notes/M11-冷启动记录.md | partial |

## 判定

| 判据 | 判定 | 说明 |
|---|---|---|
| C1 | pass | 任务书要求与记录格式落在 `.sdo/notes/M11-冷启动记录.md`。 |
| C2 | pass | 记录含步骤命令/exit/产物与手改清单（含文件:行）。 |
| C3 | partial | 该轮手改 >0（手改清单 5 类），按卡面规则 R49 至多 partial；未把有手改的一轮记成 pass。 |

语义：不适用（本卡是流程/记录卡，判据均为结构可判；语义由评审确认）

## 评审

- 评审者：reviewer-3（独立席位，第 1 轮）
- 语义自检：C1/C2 以记录原文可复跑 grep 验证；C3 按手改清单判 partial，未把有手改的一轮记 pass。
- 不可变异确认 C1：任务书与记录是历史产物，无代码分支可单独改坏，伪造记录不算证据。
- 不可变异确认 C2：命令/exit/产物与手改清单来自当轮记录，改坏等于伪造历史。
- 不可变异确认 C3：判定规则由评审按记录应用，脚本无独立分支。
