## 意图

## 风险标记

## 对齐

- C1/C2：`declare --list --preset <name>` 从 preset 文件解析每门映射（C4 用“改 preset 输出跟着变”证明非硬编码）。
- C3：`init.mjs`/计划模板改成“冻结段三行声明；preset 只是参考，真源不写 preset 字段”。

## 判据

| 编号 | 判据 | 类型 | 反例 |
|---|---|---|---|
| C1 | `declare --list --preset <name>` 输出组合阶段与每门映射，值取自该 preset | 结构 | 改 preset 的 `id: G_repair_fix` ⇒ 输出行名变化 |
| C2 | `skills/sdo-flow/references/04-参考资源.md` §2 与 `skills/sdo-flow/references/02-脚本使用.md` 给出取映射命令 | 结构 | 删两处命令句 ⇒ 两文件 grep 0 |
| C3 | `init` 生成的计划 §3 不含 `preset` 字段写法 | 结构 | 临时目录 init 后 `grep -c 'preset：'` 非 0 |
| C4 | 映射不是硬编码第二份（改 preset ⇒ 输出跟着变） | 结构 | 改 preset 判据后 list 输出同步变；写死则不跟 |
| C5 | 归档/里程碑/签字冻结区零改动 | 结构 | 真树改任一冻结文件 ⇒ git status 非空 |

## 假设

- A1：preset 的 `stages:`/`gates:` 格式是映射唯一来源；格式变更时解析器需同步（否则 C1 输出缺门，停）。
- A2：`init.mjs` 的计划 §3 是硬编码模板文案，不是从 `templates/计划.md` 复制；两处需同步（C3 反例）。

## 预览

改 `skills/sdo-flow/scripts/milestone.mjs`（`--list --preset` 解析器）、`init.mjs`（计划 §3 文案）、`templates/计划.md`（同步文案）、`skills/sdo-flow/references/04-参考资源.md`/`skills/sdo-flow/references/02-脚本使用.md`（命令指针）。验证：list 输出四门映射；改 preset 一条后输出变；`/tmp` init 后 `grep -c preset：`=0。
