# M4-4 · `check --plan`（计划与卡面漂移）

status: done
owner: impl-core
write_scope: [skills/sdo-flow/scripts/check.mjs, skills/sdo-flow/SKILL.md（§11）, README.md]
read_refs: [.sdo/cards/M4-3.md, .sdo/台账.md, .sdo/readings/M4.md]

## 意图
把“计划与卡面对不上”做成机器检查：卡表里的写域/依赖、判据点名的文件，必须与卡面一致且在写域内。

## 风险标记

risk_flags：无

## 对齐
- 该做：`check.mjs --plan` 校验：①卡表列的卡都存在文件；②卡表依赖 ⊆ 卡面「准入」依赖、且都指向更早的卡；③判据/证据点名的路径 ⊆ `write_scope`（括号 `（§11）` 只作说明、不参与比对）。
- 不该做：判断判据写得对不对、替人改计划。

## 判据
C1 卡表与卡文件双向一致：表里有卡没文件 / 有文件没进表 ⇒ exit 1，消息固定 `ERROR .sdo/01-计划.md:<行>: 卡表有卡无文件：<卡>`、`ERROR .sdo/cards/<卡>.md:<行>: 卡不在本里程碑卡表：<卡>`。
C2 依赖漂移（解析规则**直接引用 `.sdo/cards/M4-3.md` C2**）：单行 `依赖：`、顿号/逗号分隔、`M4-0…M4-4` 区间展开、剥括号与提交号；卡表依赖与卡面「准入 - 依赖」不一致（多/少）⇒ exit 1，消息 `ERROR .sdo/cards/<卡>.md:<行>: 依赖与计划卡表不一致：卡表=[…] 卡面=[…]`；前向依赖（依赖号在本卡之后）⇒ exit 1。
C3 路径漂移（定死）：扫「## 判据」「## 证据」「## 预览」三段里**所有反引号片段中的仓库相对路径**（不限前缀；**只认含 `/` 的路径与根级已知文件名**，`secret.md` 这种单段名不扫，避免误伤正文词）；路径 ∈ **`read_refs`（新增可选字段，只读引用白名单）** ⇒ 不算漂移；否则 exit 1，消息固定 `ERROR .sdo/cards/<卡>.md:<行>: 判据点名的路径不在 write_scope/read_refs：<path>`。
  理由：判据里会引用“读”的文件（如 `.sdo/台账.md`、`.sdo/readings/M4.md`），这与“写域”是两件事；用 `read_refs` 显式声明只读引用，比按前缀猜或被基线读引用打成假红更可靠。
  **豁免行（定死）**：三种段里，含「反例」「示例」「例如」「对照」任一词的**整行**不参与 C3 扫描（卡面写反例/fixture 用）。这样反例路径不必塞进 `read_refs`，也就不会让卡对自己的反例失去检测力。
  约束：`read_refs` 只允许写**真实要读**的文件；把示例路径塞进 `read_refs` 属误用（评审可据此打回）。
C4 路径归一（写死，示例）：①括号一律剥除（`skills/sdo-flow/SKILL.md（§11）` ≡ `skills/sdo-flow/SKILL.md`）；②目录/`**` 按前缀覆盖（`skills/sdo-flow/references/`、`/tmp/**`）；③相对路径按 `skills/sdo-flow/` 归一（计划表写 `templates/台账.md` ≡ 卡面 `skills/sdo-flow/templates/台账.md`）；④只认反引号片段，正文提及不算。
C5 反例夹具：可复现（写死用 **M4-0**）：`cp -a` 到 `/tmp/pl`，①删 M4-0 写域里的 `skills/sdo-flow/templates/台账.md` ⇒ exit 1；②把 M4-0 判据点名的路径改到写域外（`src/x.ts`）⇒ exit 1；恢复 ⇒ exit 0。
C6 **卡表写域 ↔ 卡面 `write_scope` 逐项相等**（新增，R18① 的落点）：卡表「写域」列归一化（按 C4）后与卡面 `write_scope` 集合比较，多/少 ⇒ exit 1，消息 `ERROR .sdo/cards/<卡>.md:<行>: write_scope 与计划卡表不一致：计划=[…] 卡面=[…]`。
C7 只读 + 退出码 + 参数：跑前跑后 `git status --porcelain` 不变；`--plan` 无漂移 ⇒ 0；有漂移 ⇒ 1；无 `.sdo/`、计划文件不存在、计划无 M4 卡表、参数错 ⇒ 2。

## 假设
A1：`write_scope` 与可选 `read_refs` 都写成 `[a, b, c]` 单行；括号内是说明（按 C4 剥除）。`read_refs` 缺省视为空。
A2：`--plan` 只查**当前里程碑（M4）**的卡表与 `.sdo/cards/M4-*.md`；历史 M1–M3 卡不重新判（否则“有文件没进 M4 表”会假红）。`--milestone <M>` 可显式指定，缺省 M4。

## 已知边界
- **声明式信任**：C3 的整行豁免（含反例/示例/例如/对照）与 `read_refs` 都是“声明即放行”——真实漂移行加「示例」、或把漂移路径塞进 `read_refs` 都能绕过。这是有意的设计（判据/反例需要写路径），机检不把它当保证，靠评审约束。
- `--milestone` 只识别 `## M<n>` 形态的段；M2/M3 是 `# 追加里程碑：M2` + `## M2.1` 形态，显式指定会 exit 2（默认只查 M4，不受影响）。
