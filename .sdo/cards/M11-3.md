## 意图

冻结段**只**写 `门禁：` 与 `判据：` 两行，它们就是唯一真源；**`preset：` 字段从真源移除**（preset 降级为“参考模板”，只用于抄写，不参与任何判定）。缺声明报错，不 fallback 任何默认集合（用户 2026-11-23 两次裁定）。

## 判据

| 编号 | 判据 | 类型 | 反例 |
|---|---|---|---|
| C1 | 冻结段缺 `门禁：` 或 `判据：` ⇒ `gate_criteria_undeclared`（exit 1，无默认集） | 边界 | 删 `门禁：` 行 ⇒ `--plan` 红并点名缺哪一行 |
| C2 | 声明 gate ∈ 已知门集合；声明判据 ∈ 判据池（如白名单） | 结构 | `门禁：G_made_up` ⇒ `gate_unknown`；池外判据 ⇒ `criterion_not_whitelisted` |
| C3 | **新签里程碑的真源字段里不再出现 `preset：`/`preset 选择理由：`**；出现即 `preset_field_removed`（已签里程碑保留为历史记录、只兼容读取） | 结构 | 在 M11 之后新签的里程碑写 `preset：` ⇒ 报该码；M1–M11 已签文件不报 |
| C4 | `--presets` 降级为“参考模板快照比对”：不一致只 WARN（不再阻断），且不再作为门禁判定依据 | 语义 | 改 `presets/` 后 `--plan` 仍 0 漂移（不再阻断） |
| C5 | `gate.mjs` 消费声明：门表缺声明中的判据 ⇒ `missing_declared_criterion` | 结构 | 门表删 `provenance.present` 行 ⇒ `gate --file` 报缺 |
| C6 | 声明行在冻结段内 ⇒ 改动使 hash 变化 ⇒ 必须追加签 | 结构 | 改判据名不追加签 ⇒ `signed_anchor_mismatch` |
| C7 | `templates/milestone.md` 与 `milestone.mjs new` 的硬编码骨架一致：把生成物的里程碑号/主题替换回 `<M>`/`<主题>`、去掉 `<!-- -->` 注释与行尾空白后，按**小节标题集合 + 必含行集合**比对（不逐字 diff）；模板不含 `preset：` 字段 | 结构 | 只改模板不改脚本（或反之）⇒ 小节/必含行集合不等，断言红 |
| C8 | `skills/sdo-flow/references/02-判据与门禁.md` 写清三件事：①“不声明=报错”②preset 只是参考模板、不参与判定 ③**规范池**（门 id 形如 `G_<stage>_exit`、判据白名单）与一份声明样例 | 语义 | `grep -c 'gate_criteria_undeclared'` ≥1 且样例含 `门禁：`/`判据：` 两行与规范池小节 |
