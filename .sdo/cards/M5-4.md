# M5-4 · 台账分卷与索引（V1 教训：禁止每次全量读）

status: open
owner: lead
write_scope: [`skills/sdo-flow/scripts/ledger.mjs`, `skills/sdo-flow/scripts/check.mjs`, `skills/sdo-flow/SKILL.md`（§11）, `skills/sdo-flow/templates/台账.md`, `.sdo/.index/`, `.sdo/archive/`]

## 意图
台账到 1 万/10 万行仍不慢：卷头元数据 + 未决索引，写 O(1)、读 O(活跃卷 + 未决项)；正文是真源，索引是可丢弃重建的派生。

## 风险标记

risk_flags：release_touching

## 对齐
- 该做：索引记 volumes + open；`rotate`/`reindex`；`index_stale` 检测；正文与索引不一致时以正文为准。
- 不该做：不自动全量重建；不把归档卷读进每次检查；不改已归档卷。

## 判据
| 判据 | 内容 | 证据怎么给（含反例） |
|---|---|---|
| C1 | 活跃卷与归档卷头部都有卷元数据注释（first/last/rows/sha256） | `head -3 .sdo/台账.md` 含该行；反例：删卷头 ⇒ `check` 报缺卷元数据 |
| C2 | 索引记录 volumes 与 open，只随追加/关闭/轮转增量更新；正文是真源、索引可由 `reindex` 完全重建 | `add`/`close` 后 open 正确；反例：手改正文不动索引 ⇒ `index_stale` exit 1 |
| C3 | `ledger.mjs rotate --to <file>` 把已关闭行搬到归档卷并更新卷头与索引；`reindex` 后再跑一次 `diff` 为空 | rotate 后 `check` 0 错、`reindex` 幂等；反例：连续两次 `reindex` 输出不同 ⇒ fail |
| C4 | `check.mjs` 检测索引漂移：手改/删行/行数与索引不符 ⇒ `index_stale` exit 1 | 三例各 exit 1；反例：所有漂移都不报 ⇒ 等于没有索引 |
| C5 | 跨卷 close 可用：原行在归档卷、close 行写活跃卷，`view ledger D-<n>` 能定位到归档卷 | 实测记录定位输出；反例：定位到错误卷 ⇒ fail |
| C6 | 10 万行合成数据：`ledger add` < 100ms、`view next` < 200ms、`check` < 300ms | 生成脚本内联、`time -p` 三次取中位、记录机器与 Node 版本；反例：任一超预算 ⇒ 判 fail 并记缺口 |

A2：合成数据只用于计时，不含真实项目内容。
