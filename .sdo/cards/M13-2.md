## 意图
把维修组合落成 presets/repair.md 并让工具能解析它（门 id 不作机检）

## 风险标记

- 无

## 对齐

- M13.6 的四门 + 判据 ⇒ `presets/repair.md` 逐字落地（C1）
- 「门名单来自 preset」⇒ C2：`declare --list` 必须列出四个 `G_repair_*`（探底已实测：`declare`/`gate --file` 都**不校验**门 id 是否在名单内，故 C2 只证“preset 被解析出来”，不证“非法门会被拒”——后者记 D-274）
- 用户口径「把组合落 preset」⇒ C3：照 preset 抄一份计划能过 `--plan`（证明 preset 是可用的说明书，不只是文件）
- C4：`presets/README.md` 索引（否则新 preset 无人发现）

## 判据

| 编号 | 判据 | 类型 | 反例 |
|---|---|---|---|
| C1 | presets/repair.md 四门与判据表齐全 | 结构 | 把 `G_repair_verify` 节改名 ⇒ `stages=4 gates=3`，C1 exit 1 |
| C2 | declare --list 出现四个 G_repair_* | 结构 | 临时副本删 `presets/repair.md` ⇒ `declare --list` 的 `G_repair_` 计数 0 |
| C3 | 照 preset 抄的计划 --plan 0 漂移 | 语义 | 把 M99 阶段序列改回 `req_design`（或删一个声明的门）⇒ `--plan M99` 报阶段/声明漂移 |
| C4 | presets/README.md 有索引行 | 结构 | 副本删 README 的 `| `repair` |` 行 ⇒ `index_rows=0` |
| C5 | 冻结区零改动 | 结构 | 副本改 `.sdo/archive/INDEX.md` 任一字节 ⇒ `git status --porcelain` 非空（真树只读） |

## 假设

- A1：`repair` 是**第五个** preset，不替代 `incremental`；两者并存，选择由计划评审按"是新建还是维修"判。
- A2：门 id 前缀 `G_repair_` 由 preset 出口表定义，不需要改脚本代码——若不成立（脚本里硬编码门 id），停并记 gap，不在本卡绕过。

## 预览

将改：`skills/sdo-flow/presets/repair.md`（四门出口勾选表 + 并行在哪 + 不适用说明）、`presets/README.md` 索引行、`skills/sdo-flow/references/02-判据与门禁.md` §9 补"落地为 repair preset"。
验证：`check --presets` 0 错；`declare --list` 含四个 `G_repair_*`；`/tmp` 夹具按 preset 抄计划 ⇒ `--plan` 0 漂移。

#### C1 命令

```bash 命令块 C1 exit=0
set -u
P=skills/sdo-flow/presets/repair.md
g=$(grep -cE '^### `(diagnose|fix|verify|integrate)\[' "$P")
b=$(grep -cE '^### `.*出口 `G_repair_' "$P")
r=$(grep -E '^\| [0-9]+ \|' "$P" | grep -vc '（core）')
n=$(grep -cE '^\| `[a-z_]+\.[a-z_]+` \|' "$P")
echo "stages=$g gates=$b criteria_noncore=$r negative=$n"
[ "$g" = 4 ] && [ "$b" = 4 ] && [ "$r" = 22 ] && [ "$n" = 19 ]
```

#### C2 命令

```bash 命令块 C2 exit=0
set -u
a=$(node skills/sdo-flow/scripts/milestone.mjs declare --list 2>/dev/null | grep -c 'G_repair_' || true)
T=$(mktemp -d); cp -a skills/sdo-flow "$T/skill"; cp -a .sdo "$T/.sdo"; cd "$T"; rm skill/presets/repair.md
b=$(node skill/scripts/milestone.mjs declare --list 2>/dev/null | grep -c 'G_repair_' || true)
cd /; rm -rf "$T"
echo "normal_gates=$a removed_gates=$b"
[ "$a" = 4 ] && [ "$b" = 0 ]
```

#### C3 命令

```bash 命令块 C3 exit=0
set -u
BASE=$PWD; T=$(mktemp -d); cp -a "$BASE/skills" "$T/skills"; cp -a "$BASE/.sdo" "$T/.sdo"; cd "$T"; S=$T/skills/sdo-flow
node $S/scripts/milestone.mjs new M99 --topic '维修夹具' >/dev/null
python3 - <<'PY'
from pathlib import Path
p=Path('.sdo/milestones/M99.md'); s=p.read_text()
s=s.replace('| <M99-0> | <卡内容> | — | <写域> |','| M99-0 | 维修夹具 | — | `skills/sdo-flow/presets/repair.md` |')
s=s.replace('阶段序列：`req_design`→`build`→`verify`→`integrate`','阶段序列：`diagnose`→`fix`→`verify`→`integrate`')
p.write_text(s)
PY
node $S/scripts/card.mjs new M99-0 --owner impl-core --intent '维修夹具' --criteria 'C1:结构:占位' --write-scope 'skills/sdo-flow/presets/repair.md' >/dev/null
node $S/scripts/milestone.mjs declare M99 --gates G_repair_diagnose,G_repair_fix,G_repair_verify,G_repair_integrate --criteria 'requirement.claimed_or_na,scope.present,node.acceptance_bound,assumption.disposed,task.complete,trace.test_linked,agent.mutation_red,agent.write_scope_disjoint,review.required,review.round_bound,review.independent,agent.reviewer_not_author,agent.checker_green,agent.findings_disposed,agent.evidence_runnable,agent.no_self_sign,agent.unverified_listed,gate.signed,node.integration_listed,mandate.revalidated,readings.recorded,agent.known_limits' --map 'G_repair_diagnose=requirement.claimed_or_na,scope.present,node.acceptance_bound,assumption.disposed;G_repair_fix=task.complete,trace.test_linked,agent.mutation_red,agent.write_scope_disjoint;G_repair_verify=review.required,review.round_bound,review.independent,agent.reviewer_not_author,agent.checker_green,agent.findings_disposed,agent.evidence_runnable,agent.no_self_sign,agent.unverified_listed;G_repair_integrate=gate.signed,node.integration_listed,mandate.revalidated,readings.recorded,agent.known_limits' >/dev/null
node $S/scripts/milestone.mjs freeze M99 >/dev/null
node $S/scripts/sign.mjs new --kind 计划 --milestone M99 --scope 'M99 计划' >/dev/null 2>&1 || true
out=$(node $S/scripts/check.mjs --plan --milestone M99 2>&1); rc=$?
echo "$out" | tail -2
cd /; rm -rf "$T"
[ "$rc" = 0 ]
```
