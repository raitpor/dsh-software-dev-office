# S5 口径变更：skill 与 agent 解耦、项目目录改为 `.sdo/`

- 时间：2026-11-19T09:34+08:00
- 选项：**待签**（三选一见文末）
- 被签对象：分支 `skill/sdo-flow`，commit `316bedd`（重构提交；本文件在其后一笔）
- 变更前口径：S3/S4 冻结的是 `sdo/` + `.dsh/skills/sdo-flow/` 的版本

## 改了什么

1. **skill 位置**：`.dsh/skills/sdo-flow/` → `skills/sdo-flow/`。原因：skill 不依赖 DSH，任意 agent 都该能用；`.dsh/skills/` 是某个宿主的目录约定。
2. **项目产物**：`sdo/` → `.sdo/`。原因：项目私有目录，且避免与工具名冲突。
3. **脚本去宿主化**：
   - `check.mjs` / `view.mjs` 不再假定“当前目录就是项目根”，改为**向上找 `.sdo/`**；找不到 exit 2。
   - `--presets` 不再执行 `git show main:docs/08-…`（那依赖某个特定仓库）：默认校验三份 preset **自洽 + 发布快照**（gate 条数、core 判据存在、id 唯一、kinds 合法），需要逐条比对时传 `--presets <判据源文件>`。
4. **文档**：`SKILL.md` 新增 §0「怎么装（任意 agent）」，并删除“插件不可用/降级”的措辞；`README.md` 重写为“另一种实现形式”；`references/07` / `references/08` / `references/03` 的宿主措辞改成“你的 agent 的提问能力”。

## 受影响的历史证据

- S1–S4 里写的旧路径（`sdo/`、`.dsh/skills/…`）**不改**：签字文件是历史记录。
- 本文件即“事实以 S5 为准”的追加说明。
- `sdo/readings/M1.md` 追加一条：R1 的含义从“本会话自动发现”变成“按安装方式可发现”（本仓库自身不再自动出现，需拷或软链到 agent 的 skill 目录）。
