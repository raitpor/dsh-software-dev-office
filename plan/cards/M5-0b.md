# M5-0b · 账号系统增强（邀请令牌 / 角色管理 / 限速）

## 意图

M5-0 的 v1 账号系统只为回答一件事：**人类在页面上注册并登录后，签字权回到人手里，且模型拿不到**。但 v1 把“谁能注册”放得太松（首个是 admin，之后一律 user），实际部署里需要有人来**控制谁能加入**、**谁能被提升**。这张卡补那三条，不改 v1 已定的会话与口令机制。

## 对齐

**复述**：在 M5-0 的 v1 账号系统之上补三件事：①**邀请令牌**——admin 在页面上生成一次性令牌（TTL 24h、只显示一次、不写日志、库里只存哈希），持令牌者可注册；无令牌 ⇒ 拒；②**角色管理**——admin 可把 `user` 提升为 `admin`、把 `admin` 降级为 `user`，但**不能撤销最后一个 admin**（`last_admin_right`），也不能改自己的角色；③**登录限速**——同账号连续 5 次失败锁 5 分钟（`login_locked`），失败计数按账号而非 IP（单机部署，IP 无意义）。

**人确认**：pending

**正例 2**
1. admin 生成邀请 → 新用户持令牌注册成功 → 该用户能登录但不能进 admin 页。
2. admin 把人提升为 admin → 新 admin 能生成邀请；再降级回去 ⇒ 权限立刻失效（会话不需要重新登录，但下次判权按新角色）。

**反例 1**
- 试图撤销最后一个 admin（或改自己的角色）⇒ 拒绝（`last_admin_right`/`self_role_change`），且不落任何状态变更。
