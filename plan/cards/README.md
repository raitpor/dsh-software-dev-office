# 卡（SDO 接管前的记录形状）

一张卡一个文件，命名 `M<里程碑>-<序号>-<短名>.md`。**动手前建卡**，不改历史段（改就新开「变更」段）。

## 为什么这么定

这些段就是 `docs/03` 的表与 `docs/02` 的事件：`意图`→`intent`、`对齐`→`restatement`+`alignment.*`、`判据`→`criterion`、`假设`→`assumption`、`证据`→`evidence`、`判定`→`gate.judged`、`评审`→`report`/`defect`。接管时按段导入，不用再翻译。

**两处刻意的降级**（接管前没有的东西，不假装有）：

- `判定` 是手工填的，**不绑 `baseline.hash`**——M2 才有冻结基线，M2 前的“绿”只对人和 reviewer 成立；
- `人确认` 可以 `pending`，但**收卡前必须不是 `pending`**（这是“假设必须处置完”的手工版）。
