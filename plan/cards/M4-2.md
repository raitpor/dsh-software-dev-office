# M4-2 · 派发租约与预占/收回

## 意图

`docs/12` 的硬规则：**卡的认领只能通过派发**——`sdo_dispatch(card)` 产出 `lease`（绑 actor + card + scope + frontier + TTL），`claim` 必须持 lease；模型自己开会话也拿不到 lease，所以“绕过派发”没有收益。预占（`task.assigned`）是 PM 的手，让“可领”收窄到某个 actor，但它**不是授权**：不改 status、不授予写权。收回（`lease.revoked`）是派发的逆操作：在飞的卡先 `blocked(lease_revoked)` 再回 `ready`，工作副本不删。

## 对齐

**复述**：`lease.issued` 是唯一入口（`dispatch` 动作，需 `dispatch@domain`）；`task.claimed` 必须持未过期、且 actor 匹配的 lease（否则 `no_lease`）；预占期内的认领者必须等于 `reserved_by`（否则 `not_reserved_actor`）；`lease.expired` 到期后卡回 `ready`、副本保留下次可续；`lease.revoked` 时在飞卡先 `blocked(lease_revoked)` 再 `ready`；**预占不是授权**——被预占但无 lease 的 actor 认领必须失败。

**人确认**：pending

**正例 2**
1. PM `dispatch(card→alice)` ⇒ `lease.issued`；alice `claim` 成；bob 拿同一张卡 `claim` ⇒ `not_lease_holder`。
2. PM 先 `assign(card→alice, expires_in)` 再派发给 bob ⇒ bob `claim` 拒 `not_reserved_actor`；预占过期后 bob 可领。

**反例 1**
- 不落 `lease.issued` 直接 `task.claimed` ⇒ 拒 `no_lease`（这条是 M1-6 之前“裸 claim”的封口）。

## 判据

| # | 判据 | 怎么验 |
|---|---|---|
| C1 | `dispatch` 是 `lease.issued` 的唯一生产者（写网关 + 能力），事件载荷含 `{card, actor, scope, frontier, ttl_s, expires_at}`；`lease` 表投影 = 事件折叠结果 | 用例：裸 append `lease.issued` ⇒ `unauthorized_lease_issue`；直插表行 ⇒ verify 红 |
| C2 | `task.claimed` 的前置：存在未过期、`lease.actor = claim.actor`、`lease.card = task` 的 lease；缺 ⇒ `no_lease`、0 事件 | 用例三条（无 lease / 别人的 lease / 过期 lease） |
| C3 | 预占：`task.assigned{task, actor, expires_at}` 只写 `reserved_by`/`reserved_until`、**不改 `task.status`**；`task.unassigned` 释放；预占期内他人认领 ⇒ `not_reserved_actor` | 用例：预占后 status 不变；他人认领被拒；预占到期后他人可领 |
| C4 | 收回：`lease.revoked` 后 `in_progress` 卡必须同时落 `task.blocked{block_code:'lease_revoked'}` 再回 `ready`（两次写同事务或幂等重放可恢复）；**工作副本不删** | 用例：撤回后卡状态序列、`workcopy` 目录仍存在 |
| C5 | 过期：`lease.expired` 由工具按 `expires_at` 落（读时判定或定时任务皆可，但必须只有一个写者），卡回 `ready`；过期后原 actor 再写 ⇒ `lease_expired` 阻断 | 用例：`at` 推过 TTL 后写被拒 |
| C6 | **预占不是授权**：被预占的 actor 若没 lease 仍不能 claim；预占本身不产生任何写权（不查 `hasRight` 的结论不被改变） | 用例：预占后该 actor 不带 lease 认领 ⇒ `no_lease` |
| C7 | `verify`：`busy` 卡必须有未过期 lease 且 `lease.actor = claim.actor`（`docs/02` 不变式 6）；预占期内认领者 ≠ `reserved_by` ⇒ 红；同一卡多条活 lease ⇒ 红 | verify 用例 + 脏数据探针 |
| C8 | 冻结区零改动 | `git diff f37f4dc -- docs design probe` 为空 |
