## 意图

把“事件是唯一真源”变成代码：一个**纯函数**把事件序列折成当前状态，重放两次逐字节相同，未知事件一律炸而不是悄悄跳过——视图（M0-3）与门禁（M2）都只能从它读数。

## 对齐

- 复述：这一卡不建视图、不落库，只回答“给定这串事件，现在的事实是什么”；它的输出会被 M0-3 的 13 个视图直接消费，所以**可重放**和**不静默吞事件**是硬要求。
- 人确认：pending（收卡前会问；不默认通过）
- 正例 1：同一串事件喂两次，`JSON.stringify(fold(events))` 逐字节相等（键序稳定）。
- 正例 2：一条 `assumption.disposed` 带无效 `decision_id`（不存在 / 非 valid / 非 `assumption_set` / 不覆盖该假设）时，fold 抛 `FoldError`，不是静默保持 `open`（评审 P1-2 改）
- 反例：fold 里有 `if (kind === 'x') { ... } else { /* 忽略 */ }`——未知事件被吞，等于真源可丢。

## 判据

| # | 判什么 | 怎么跑 | 正例 | 负例 |
|---|---|---|---|---|
| C1 | 纯函数 | 静态检查 + 一次运行 | 无 `fs`/`Date.now`/`process.env`/随机；输入只有 events 与起始状态 | 函数里读时钟或写库 |
