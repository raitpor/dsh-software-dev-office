# M2-5 · PM 最小环路（读队列 → 建卡 → 预占/派发 → 请求签字）

## 意图

M0/M1 的 `pm_queue` 是**只读视图**：能看见“该谁动”，但没有动作能推进它。M2 落最小环路：PM（Lead 或 M3 之后的 SDO）读 `pm_queue`/`alignment` → **建卡**（`task.created`，卡必须有意图与判据）→ **预占/派发**（`task.claimed`，写域即边界）→ **请求签字**（`request_sign`，只有人能签）。`escalate` 与独立性检查留 M3。

依据：`docs/07` 决策权矩阵与 §5 授权（grant 在 M4 前恒空）、`docs/15` PM 环路、`docs/05` `pm_queue` 的 7 个 `reason_code`、`docs/03` §4 解阻塞白名单。

## 对齐

**复述**：不是“给 PM 加一组写接口”，而是**让队列的每一行都有一个合法动作能把它推走，且这个动作留痕**。三条硬约束：①PM 不能给自己没权限的卡派工（`no_permission` 在派发前就拒，不是执行时才炸）；②PM 不能代签（`request_sign` 只产生请求）；③解阻塞只能动白名单里的 `reason_code`（`lease_expired`/`lease_revoked`），其余只能 `rework`/`attention`。

**人确认**：pending

**正例 2**
1. `pm_queue` 里一行 `reason_code='waiting_review'` ⇒ PM 派一个评审卡给 `reviewer`（`task.claimed`，`owner='reviewer'`）⇒ 队列刷新后该行消失、新评审卡出现在 `review_queue`；`actor` 与 `at` 可追。
2. 一行 `reason_code='awaiting_signature'` ⇒ PM 发 `request_sign` ⇒ 产生**待签请求**（不是 decision 行），人签后队列消失；期间 PM 再发一次同内容 ⇒ 幂等，不产生第二个请求。

**反例 1**
- PM 尝试 `assign` 一张写域属于 `impl-core` 的卡给 `impl-surface` ⇒ 事先拒（`scope_mismatch`），卡状态不变。

## 判据

| # | 判据 | 怎么验 |
|---|---|---|
| C1 | **建卡必带意图与判据**：`task.created` 缺意图/判据/写域 ⇒ 拒（`card_incomplete`）；这条与 M1 的对齐三件套不冲突（PM 建卡可以先 `open`，但收卡前不得仍缺） | 用例：缺判据 ⇒ 拒；完整 ⇒ 落行 |
| C2 | **预占/派发前查权限**：`assign` 时校验 owner 的 `right` 覆盖该卡写域；不覆盖 ⇒ `no_permission`（**事先拒**，不是到 `admission` 才炸）；`grant` 在 M4 前恒空，故 M2 的权限只来自静态 `right` 表 | 用例：跨泳道派工 ⇒ 拒；同泳道 ⇒ 通过 |
| C3 | **不代签**：`request_sign` 只落“待签请求”，不产生 decision 行；PM 自己不能用 `sign` 动作；请求幂等（同内容重复请求不叠加） | 用例：PM 调 `sign` ⇒ `not_a_signer`；重复 `request_sign` ⇒ 1 个请求 |
| C4 | **解阻塞白名单**：只允许 `lease_expired`/`lease_revoked` 走 `unblock`；其余 `reason_code` ⇒ 拒（`not_unblockable_by_pm`），只能 `rework` 或 `attention`；解完一律回 `ready` 并清 lease | 用例：7 个 reason_code 逐个尝试，只有 2 个可解；解完 `lease` 为空 |
| C5 | **每行有合法动作**：`pm_queue` 的 7 个 `reason_code` 每个至少映射一个动作（`rework`/`assign`/`attention`/`request_sign`/`unblock` 之一），且动作执行后该行确实离开队列（或变成别的行） | 用例：7 行各推一次，队列状态变化符合 README 表 |
| C6 | **`plan`/`assign` 最小版权**：M2 只给 PM 最小集（建卡、派发、请求签字、rework）；`escalate`、grant、独立性检查留 M3，接口存在但调用 ⇒ `not_implemented` 且不留半截状态 | 用例：调 `escalate` ⇒ 明确拒绝码 |
| C7 | **动作全部留痕**：每个动作落对应事件（`task.created`/`task.claimed`/`attention.raised`/`request_sign`），`actor` 为 PM 本人；`verify` 能重放出同样的队列状态 | 用例：动作序列重放后 `pm_queue` 逐行相等 |
| C8 | 冻结区零改动 | `git diff f37f4dc --name-only -- docs design probe` 为空 |
