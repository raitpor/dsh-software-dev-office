**遗留风险（交 M0-1 与 M2 打包复验）**：① 裸 `npm ci` 会触发 npm 11.20 对 `binding.gyp` 的自动 `node-gyp rebuild`（13.x 的 `gypfile:false` 未生效），项目因此钉 `npm ci --ignore-scripts`，M2 宿主打包/CI 必须沿用；`--ignore-scripts` 是全局的，后续引入需要 build 的依赖要复核。② 13.x 的 `exports` map 缺 `"types"` 条件，`tsconfig.paths` 垫片依赖 `node_modules` 路径；上游修复后重试删除。③ 加密库首次打开约 106.9ms（原生模块 + key 派生），属进程启动成本，M0-1 建库时应量化并避免每次查询重开。④ 13.0.3 内置 SQLite 3.53.4，与 `node:sqlite` 的 3.54.1 不同版本，跨路径读同一库（备份/工具链场景）需单独验证。
