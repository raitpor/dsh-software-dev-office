# 签字记录

M0 阶段还没有 `signerd`（M2 才有），所以这里的“签字”是**人明确点头 + 落一行记录**，不是密码学签字。每条记录写清：签的什么、签的是哪棵树、签的人当场确认了什么。

约定：
- 只由签署者（用户本人）签字；Lead 只负责把待签内容整理到可签的程度，**不能代签**。
- 记录里必须带**被签对象的哈希或提交号**，否则“签的到底是哪一版”说不清。
- 实现期的判定在 M2 之前都是手工的（`plan/04-流程执行细则.md` 的刻意降级），这里记录的是手工判定的签署动作。
