| 1 | 工作副本用什么 git、目录放哪 | **用设计已定的内置 git：`isomorphic-git`（纯 JS / MIT / 随插件分发 / 不执行 hooks），不用系统 git CLI**。目录按 `docs/07` §12：`.work/<card>/`、`.sdo/vcs-objects/`、`.sdo/vcs-cards/<card>.git/`，三者都被 `.gitignore` 覆盖。`docs/10` §3 把对象库简写成 `.sdo/vcs/`，与 §12 的目录图不一致 ⇒ 记 **D-118**，实现以 §12 为准，冻结期内不改 `docs/`，v2.1 由人签对齐 |

| 3 | lease TTL 缺省值与矩阵缺行 | **lease TTL 缺省 4h**（`config` 可覆盖，不进 baseline）；`docs/07` §2 矩阵若缺 `dispatch`/`assign` 行 ⇒ **补行 + 迁移**（补行不是新造动作） |
