# 偏差台账（实现 ↔ design-v2.0）

> 规则见 [../FREEZE.md](../FREEZE.md) §3：**先记再绕，不记不许绕**。每条都要能被 `verify` 或评审复现。

## 怎么记

| 字段 | 写什么 |
|---|---|
| 编号 | `D-001` 递增，不复用 |
| 类型 | `explain`（设计没写死，按 X 解释）/ `gap`（设计缺失）/ `defect`（设计错） |
| 撞上的地方 | 卡号 + 代码位置 + 设计条款（`docs/…` §N 或 `design/…` P N） |
| 现象 | 一句可复现的话；带报错原文或反例输入 |
| 代价 | 绕过去的代价（返工单元、额外字段、临时开关） |
| 建议 | 下个设计版本怎么改（`gap`/`defect` 必填） |
| 状态 | `open` / `accepted`（人确认按解释走）/ `fixed-in-v2.x` |
