# SDO v2 · 设计案索引

> 本目录是 **SDO v2 的设计案**（仓库 `main` 分支即 v2）。v1 源码已移出工作树，见分支 `v1` 与 tag `v1-final`。
> 版本管理**只用 git**：`git log -- docs/` 即变更历史；漂移检查 `python3 docs/check.py`。
>
> **合并原则（防漂移）**：一个事实只有一个家。合并过的模块不再保留副本，跨篇只许**引用**，不许复述。
>
> **理论底座**：[01 理论与边界](01-理论与边界.md)（三个真源、五个命题、注意力预算、相关工作与局限）。概念与落地分居两处：概念在 01，字段在 02–13。

## 一句话

**v2 把"过程纪律"从"写在文档里、靠人记"改成"写在数据模型里、绕不过去"**：真源是数据库里的服务（不是仓库里的文件），观测只能走视图（不能 bash 猜），声明只能是真源的投影（不能手拼），签字是密码学意义上的签字（不能代签），子代理越界会被**检测并拒绝准入**（不靠它守规矩）。

## 术语表

| 词 | 定义 |
|---|---|
| **真源** | 唯一的、只能追加的事件序列；其它一切都是它的投影 |
| frontier | 真源当前位置的因果闭包（`EventId` 集合）；判据与签字只绑它；`frontier_hash = sha256(规范化(frontier))` |
| **claim** | 对状态的断言，只能由视图产生，不能手写 |
| **判据** | 可执行的检查，带修法、正例、负例；红了就是红 |
| **门禁** | 判据的固定编组，绑到某个阶段出口；verdict 由读数算出 |
| **baseline** | 判据/门禁/阈值/引擎版本的冻结清单，带内容哈希 |
| **producer** | 产出被评对象当前内容的 actor；签字者与评审者不得是它 |
| **will_change** | preview 回执里"确认后会改动什么"，不是待办 |
| **独立性** | 关键决策的复核要求：`dual_human` 或 `solo_cooldown`（弱保证必须明示） |
| **goal_node** | 分解节点：把目标逐层拆成可独立验收的块；由人声明，不在运行时自生长 |
| **integration** | 集成清单：父节点逐子标记接上/未接/放弃；父验收看它，不看"子都绿" |
| **snapshot / workcopy** | 内容寻址的快照 / 某张卡从快照检出的独立工作副本 |
| **work_unit** | 一卡一判据一证据的一行 |
| **attention / report** | 待人工回答的结构化问题 / 执行者的进度报告（六态，与生命周期分开） |
| **parked / dead** | 停泊（可唤醒）／退役（无法唤醒）；只有后者算退役 |
