# SDO v2 · 设计案索引

> 本目录是 **SDO v2 的设计案**（仓库 `main` 分支即 v2）。v1 源码已移出工作树，见分支 `v1` 与 tag `v1-final`。
> 设计案的**变更日志**见 [HISTORY](HISTORY.md)；漂移检查 `python3 docs/check.py`。
>
> **合并原则（防漂移）**：一个事实只有一个家。合并过的模块不再保留副本，跨篇只许**引用**，不许复述。

## 一句话

**v2 把"过程纪律"从"写在文档里、靠人记"改成"写在数据模型里、绕不过去"**：真源是数据库里的服务（不是仓库里的文件），观测只能走视图（不能 bash 猜），声明只能是真源的投影（不能手拼），签字是密码学意义上的签字（不能代签），子代理越界会被**检测并拒绝准入**（不靠它守规矩）。

## 术语表

| 词 | 含义 |
|---|---|
| **真源** | 唯一的事实来源：数据库里的事件表（append-only）。不是文件，不进 git。 |
| **折叠 / fold** | 由事件算出派生状态的纯函数；增量可用。只有它可以读事件表。 |
| **声明 / claim** | 系统对外说的一句话（回执、报告、注入里的每个断言）。只能是视图/投影的结果。 |
| **frontier** | "到哪一组事件为止"——一组事件 id（向量时钟扁平化），取代"第几条"。签字与读数有效期都绑它。 |
| **意图 / intent** | 人真正想要的东西；只能由人写入、人签字。 |
| **判据 / criterion** | 一段可复算的检查，三态（通过/失败/不适用），必带正例与负例。 |
| **视图 / view** | 只读查询面（SQL 视图 + 元数据）。agent 与 UI 都只能通过它观测。 |
| **准入 / admission** | 子代理产物进入基线的唯一闸门：diff ⊆ 授权范围 + 锁 + 判据。 |
| **签发 / sign** | 人类用签章口令对"命题 + 证据 + frontier"的密码学签名；不可代签、不可盲签、免密必绑 frontier。 |

## 与 v1 的关系（一句话）

v1 的**判据语义**（三态、fail-closed、证据绑定、顺延定价、变异自证）是资产，**搬运**；v1 的**外壳**（文件真源、每轮注入、字符串回执、双份计算、无预算、角色卡）是病灶，**重写**。迁移策略见 [13](13-迁移-里程碑与验收.md)。
