# 总览与边界

> 本文定义 v2 是什么、不是什么、怎么算成功。细节见各模块文档。

## 1. 一句话定位

**v2 是一个"过程真源 + 审计面"的服务**：它不替人做判断，它保证**每个判断都有出处、有证据、有签字**，并且**没签的东西不能当结论用**。

三层职责：

```text
┌────────────── 人 ──────────────┐   看视图、批事项、签字
│   UI（tab 页 / 页面 / 待审队列） │
├──────────── agent ─────────────┤   查视图、做动作、申请签字
│   sdo_query / sdo_act / check   │
├──────────── 真源 ──────────────┤   事件表 + fold + 物化视图（DB）
│   db（sqlite 缺省 / postgres）   │
└────────────────────────────────┘
```

## 2. 范围

**做（in）**

- 真源：事件表、fold、物化视图、并发写与冲突拒绝（[03](03-真源-存储事件与折叠.md)）；
- 链条：意图 → 条款 → 验收场景 → 判据 → 证据 → 声明（[04](04-链条-意图到声明.md)）；
- 判据与门禁：三态、负例夹具、预算、豁免、变异自证（[05](05-判据-门禁与负例.md)）；
- 工具面：一个只读 `query`、一个写 `act`、一个 `check`，视图由数据驱动（[06](06-观测-视图工具与预算.md)）；
- 交互：类 `dsh-context` 的一级页面 + 会话 tab + 待审队列（[07](07-交互-界面与待审队列.md)）；
- 签字：登录 + 签章口令 + 独立签名进程 + 免密窗口 + 撤销（[08](08-签字-身份与免密.md)）；
- 协作与并行：权限绑 scope、worktree/锁/复用、子代理约束（[09](09-协作-权限-并行与子代理.md)）；
- 方法论与交付：policy 数据 + 时序断言（[10](10-方法论与策略.md)）、release 与冻结（[11](11-交付与版本.md)）；
- 横切：语言无关、安全与脱敏（[12](12-横切-语言无关与安全脱敏.md)）；
- 迁移：v1 冻结只读、里程碑与判死读数（[13](13-迁移-里程碑与验收.md)）。

**不做（out）—— 明确写下来，防止"只增不减"**

- 不做"通用项目管理"（甘特、工时、OKR）——它只服务"可验证的软件过程"；
- 不做"代码质量分析"（lint、覆盖率工具）——它消费这些结果，不生产；
- **不接管宿主的派发与压缩**；不替宿主编排上下文预算（只**声明**所需预算）；
- **不对宿主提要求**：宿主所有权不在使用者手里，v2 只依赖"能读写工作区 + 能起子会话 + 能注册工具 + 能访问自己的库文件"（[09](09-协作-权限-并行与子代理.md)）；
- 不做聊天框：交互是**视图与决策**，不是对话；
- 不做"AI 自动签字"：任何形式的代签都在禁区（[08](08-签字-身份与免密.md)）；
- **不内置方法论包**：生命周期、设计方法、测试方法只以 policy 数据 + 可机械检查的时序断言存在（[10](10-方法论与策略.md)）。

## 3. 与 v1 的关系

| 方面 | v1 | v2 |
|---|---|---|
| 真源 | `.sdo/` 文件（gitignore 忽略） | 数据库（sqlite 缺省） |
| 观测 | 文件 + `bash` 猜 | 视图（唯一观测面） |
| 声明 | 字符串拼装 | `claim` 表投影 |
| 判据 | 68 条，缺负例 | 判据即数据 + 强制负例 |
| 签字 | 工具参数里的字符串 | 密码学签名（独立进程） |
| 并行 | 轻量 git 字符串写范围 | worktree + 锁表 + 准入 |
| 角色 | 四张角色卡 + 掩码 | 权限绑 scope（无角色卡） |
| 预算 | 设计写了，无判据 | 类型化预算，超限结构化截断 |

**搬运**：判据语义（三态、fail-closed）、证据绑定、顺延定价、变异自证、追溯边。
**重写**：外壳（真源、观测、回执、注入、派发编排）。
**冻结**：v1 台账转为只读档案，供查证（不进 v2 真源）。

## 4. 成功度量（可测，不许写成形容词）

| 指标 | 定义 | 目标 |
|---|---|---|
| **单一出口** | 一次 `status` 查询中，事件表被读的次数 | **= 1**（一次 fold 或一次视图查询） |
| **观测走工具** | 一个会话里 `query` 调用数 / `bash` 调用数 | **> 1**（v1 是 8 / 1813 ≈ 0.004） |
| **预算守约** | 每轮注入字节的 P95 | 达到 [06](06-观测-视图工具与预算.md)「预算常量」 |
| **声明可追** | 回执里每一句结论都能在 `claim` 表找到行 | **100%** |
| **死字段** | 无消费者的字段数 | **0** |
| **判据冤枉** | 负例夹具红的判据数 | **0**（红了就修判据） |
| **签字不可代签** | `decision` 行全部有密码学签名且 signer ≠ 生产者 | **100%** |
| **读延迟** | `sdo_query` 的 P95（100 万事件库） | 达到 [03](03-真源-存储事件与折叠.md)「三条预算线」 |
| **脱敏覆盖** | 对外出口经脱敏器的比例 | **100%**（快照导出后 grep 命中 0） |
| **语言无关** | 引擎源码里语言名作为分支条件的次数 | **0** |
| **越界可发现** | 子代理越界被 `boundary.violation` 记录的比例 | **100%**（准入时必查 diff） |
| **本地化完整** | 两包键集相等 + 引擎硬编码文案数 | 相等 · **0** 处 |
| **双平台一致** | Linux 与 Windows 两套 CI 全绿；同一仓库快照下 `fold`/`verify`/`claim` hash 相同 | 全绿 · 逐字节相同 |

这十三个数字就是 v2 的"健康度"；它们全部可复算，且每个都有"现在是多少"的对照。

### 4.1 反指标：每条度量都要有对手

度量一旦成为目标就会被优化，而且**优化的方式通常最省事**（v1 的 `C-66` 就被“清零”过）。所以每条度量配一条反向指标——两者同时偏离，说明在作弊。

| 度量 | 反指标 |
|---|---|
| 观测走工具 > 1 | **`query` 返回字节中位数不得上升**；`bash` 次数不得为 0（读代码仍须用 bash） |
| 预算守约 P95 < 1500 | **关键段必现率**（`frontier` / 结论 / 原因码必须出现）；“看不懂/缺信息”反馈数 |
| 声明可追 100% | 每份回执的**人类可读字段数 ≥ N**；抽样“可据以行动”判定 |
| 死字段 = 0 | **判据 `caught=0` 的比例**；判据总数增速 |
| 判据冤枉 = 0 | **退休判据数**；每条判据的 `caught` 值 |
| 签字不可代签 100% | **签字数 / 决策数**（防“签字通胀”）；单次签字耗时 |
| 读延迟（门槛见 [03](03-真源-存储事件与折叠.md)） | **确定性**（同 `frontier` 同结果）；陈旧读数投诉数 |
| 脱敏覆盖 100% | 脱敏后回执的**可复算率**（能否据它复现结论） |
| 语言无关 = 0 | **适配器覆盖率**（支持的语言数）；抽样人工审“是否换马甲绕过” |
| 越界可发现 100% | **越界数 / 写入数**（分母必须独立统计，不能自报） |
| 本地化完整 | **语言包使用率**（某语言长期 0 使用 ⇒ `retired_candidate`）；译文与基准包**语义偏离**抽样 |
| 双平台一致 | **平台分支处数**（`process.platform` 出现在业务逻辑里即需说明理由）；Windows 被跳过的用例数（应为 0） |

### 4.2 使用规则（四条硬约束）

1. **度量只进报告，永不进门禁。** 判据是“必须过”的线，度量是“观察趋势”的仪表；仪表一旦变成红线，人就只学会看表盘不看路。由判据 `metrics.not_gate` 干检：**任何判据读度量值即红**。
2. **反指标不得由被考核方自报。** 分母必须来自引擎自己的计数（例如“越界/写入”的分母是写入事件数，不是 agent 自述）。
3. **季度人工抽样**：抽 **5 份真实回执**，由人判“能否据以行动”；不通过则回查对应度量。
4. **度量会过期**：连续 **3 期完全不变**（说明没人真用它做决定）⇒ 标记 `retired_candidate`，进 `v_gaps`。防止仪表盘通胀——v1 的登记表就是这么长起来的。

## 5. 用户与部署形态

| 形态 | 存储 | 谁在用 | 说明 |
|---|---|---|---|
| **T0 单人** | sqlite 单文件 | 一个人 + 若干 agent 会话 | 装完即用，零服务 |
| **T1 小团队同机/同卷** | sqlite + WAL | 2–5 人、多个 dsh 实例 | 明确**不支持网络卷** |
| **T2 多人多地** | postgres | 真团队 | 需要服务、备份、鉴权 |

配置一块，缺省 T0：

```yaml
store:
  driver: sqlite            # sqlite | postgres
  url: ~/.local/share/sdo/<project>.db
```

**"缺省即单人"是承诺**：不要求用户先起数据库。

## 6. 节奏

- **M0–M4** 见 [13](13-迁移-里程碑与验收.md)；每个里程碑有"判死读数"，读数不达标不进下一步。
- 包版本 **从 `0.2.0` 起**：沿用同一个包名（npm 不接受低于 0.1.6 的版本），而语义上 v2 是**第二次架构**，不是 0.1.x 的延续。
