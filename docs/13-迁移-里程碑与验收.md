# 迁移、里程碑与验收

> 原则：**核搬运，壳重写，历史冻结**。不整体推倒（v1 自己的评估已论证），但也不在旧壳上继续打补丁。

---

## 1. 迁移策略：B（v1 冻结只读）

| 方案 | 代价 | 结论 |
|---|---|---|
| A 事件映射器（v1 journal → v2 event） | 高：10 410 条要逐条重验语义 | 不做 |
| **B v1 冻结为只读档案，v2 新台账** | 中 | **采用** |
| C 双写过渡 | 最高 | 不做 |

**v1 冻结的具体做法**

- 仓库根保留 v1 代码与 `.sdo/`（只读）；`dsh plugin` 不再加载 v1 的写路径；
- 提供 `sdo1 export` 只读导出（人可查历史卡、缺陷、评审）；
- **v1 的判据库、测试用例、语言键是资产**：逐条迁到 v2（判据要补负例，见 [05](05-判据-门禁与负例.md)）。

**哪些资产搬、哪些不搬**

| 资产 | 处理 |
|---|---|
| 判据语义（三态、fail-closed） | 搬（补负例） |
| 证据绑定（产物指纹 + frontier） | 搬（frontier 取代 seq） |
| 顺延定价（scope / nonScope + 人签） | 搬（表结构重写） |
| 变异自证 | 搬（记录落 evidence） |
| 1 883 个测试用例 | **按价值搬**：产品行为类搬，字符串比对标 bbox 类不搬 |
| 68 条判据 | 搬（逐条审"它挡哪条漂移"，挡不住的退休） |
| `office.ts` / `index.ts` | **不搬**（壳重写） |
| 每轮状态块注入 | **不搬**（由 UI + 视图取代） |

## 2. 里程碑（每个都有判死读数）

### M0 · 真源与视图（2–3 周）

**做**：SQLite schema + 约束 + 8 个视图 + `fold` + `sdo_query` + 只读控制台页（3 个页面）。

**判死读数**

1. 一次 `status` 查询中 `event` 表读取 **1 次**；
2. 同一 `as_of` 两次查询**逐字节相同**；
3. agent 用 `bash`/`read` 触达 DB 文件**失败**（沙箱）；
4. `v_gaps` 能看到 `query_miss` 的聚合。

### M1 · 链条与判据（2 周）

**做**：intent/spec/scenario/criterion/evidence/claim 六表 + 判据注册（强制负例）+ `sdo_check` + 门禁判定。

**判死读数**

1. 抽 20 条 v1 结论型回执，在 `claim` 表能重建 **20/20**；
2. 新增判据无负例 ⇒ **注册被拒**；
3. 新增真源字段无消费者 ⇒ `dead_field` **红**。

### M2 · 交互与签字（2–3 周）

**做**：待审队列（四项契约）+ 登录 + 签章口令 + signerd + 免密窗口 + 撤销。

**判死读数**

1. 未解锁时签字 ⇒ `awaiting_unlock`，**不产生** decision 行；
2. 免密窗口内，frontier 改变后签字 ⇒ **要求重新解锁**；
3. decision 缺 `proposition` ⇒ `no_blind_sign` 红；
4. agent 尝试签字 ⇒ 拒绝 + 告警事件。

### M3 · 协作与权限（1–2 周）

**做**：actor/scope/right、冲突可见、双人签。

**判死读数**

1. 两人并发改同一字段 ⇒ `disputed`，卡不能 `done`；
2. 版本冻结只有 1 个签字 ⇒ 门禁红；
3. 撤销权限后待审项消失且显示"申请入口"。

### M4 · 并行与复用（2 周）

**做**：worktree、锁表、公共面单写者、复用 reason code。

**判死读数**

1. 同文件并发写：**一成一败（409）**；
2. 一次派发的 `reuse.skipped` **≤ 1 条**；
3. 连续 3 次新起 ⇒ 告警进 `v_gaps`。

> 总计约 **9–12 周**（单人 + agent 协作）。若某个 M 的判死读数不达标，**不进下一个 M**，先修。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
| 重写后"判据库"退化 | 搬迁时逐条问"挡哪条漂移"；挡不住的退休，不许原样搬 |
| 里程碑拖期 | 每个 M 有判死读数；不达标停，不叠加 |
| 单人开发无人评审 | 用 agent 做评审，但**判据与签字不能由 agent 代**；人签集中在 M2 |
| v1 历史丢失 | 只读导出 + 快照；不要求可复算 |
| 需求膨胀 | 任何新机制必须能回答"挡哪条漂移"，否则不进 v2（[01](01-理论支撑.md)） |
