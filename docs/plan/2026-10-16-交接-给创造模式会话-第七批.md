### 3.2 `DEF-084`（major，**open**）—— 非 ASCII 路径永不匹配（**违反"语言无关"长期约束**）

**现象**：`src/infra/git.ts` 用 `git status --porcelain` 的**默认**输出解析路径，而 git 默认 `core.quotePath=true` ⇒ **非 ASCII 文件名被八进制转义**（`文档/说明.md` 打印成 `\346\226\207…`），而 `git.ts` **只剥外层引号、不做反转义** ⇒ 转义串与写范围里的真名**永不相等** ⇒ 命中恒为 0。**实测（V14）**：写范围 `文档/说明.md` + 该文件脏 ⇒ `tracked=["\346\226\207…"]`、比较 `false`、命中 0（本应 1）；加 `-z` 复算 ⇒ `["文档/说明.md"]` ✓。**这不是苛刻边角**：本项目长期约束是**语言无关**，而中文名在本仓是常态（`docs/plan/2026-10-15-交接-…md` 此刻就带着转义躺在读数里）。
**修法**：`git status -z`（或 `-c core.quotePath=false`）并按 `\0` 切分；**不要自己写一份"反转义"实现**（优先让 git 直接给原文）。
**DoD**：① **中文名**脏文件必须命中（正例）；② 英文名同义（对称反例）；③ 带**空格 / 引号 / 反斜杠**的名字不许崩、不许误判（各一格，或说明为什么不测）；④ 口径**语言无关**（不写死任何语言/字符集，不针对本仓路径）；⑤ 不得影响既有英文路径读数（回归）。
**验收**：**行为**（中文名 / 英文名 / 特殊字符 三态）+ **结构**（无第二份路径实现）。

## 7. 已知的坑（本批新增）

1. **`lib/` 与 `.sdo/` 都不被 git 跟踪** ⇒ 判"有没有改产物/台账"**必须**用 `find -newermt`（+ `lib/` 整树 sha256），`git status` 看不出来。
2. **`npm test` 会重建 `lib/`**（`npm run build && …`）⇒ 只读会话直接跑 `node scripts/run-tests.mjs`。

6. **先看现盘、再写口径**：驾驶舱这两轮连续栽在"只用一个口径去数"（`asOf` 计数、以及把 `m179` 的覆盖面说成"全盲"）⇒ 涉及**计数/枚举/覆盖面**的结论，**换一个口径复算一遍**再落笔。
