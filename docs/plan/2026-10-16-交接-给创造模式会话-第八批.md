### 3.1 `DEF-080` **F5**（major，**open**）—— glob/宽范围写范围**整类豁免且不提示**

**现象（V15 实测）**：**字面 glob 形态**的写范围（`src/**/*.ts`、`src/*`）**命中 0 ⇒ 既不拦也不提示**；而**真台账里 `TASK-006.yml` 的写范围就是 `src/integration/**`** ⇒ **与被刚修掉的「单路径收窄」是同一类整类豁免**。执行会话的 §8 里**也没有** DoD③ 要求的宽范围/glob 判定表（V15 在它报告 **§3.3 补了 7 行实测表**，请先读它）。
**修法**：让判定回答"**某个具体脏文件是否落在该卡写范围的展开域内**"。**先读再定**：`src/domain/plan.ts` 的 `scopeOverlaps` 是否本就支持 `**`/`*`（它是路径代数的唯一出口）；若支持 ⇒ 问题在**调用姿势**；若不支持 ⇒ 在**同一个出口**上补 glob 展开，**不许在 `git.ts` 里另写一份匹配**。
**DoD**：① **glob 写范围 + 域内脏文件 ⇒ 必须命中并点名**（含 `src/integration/**` 这种真台账形态，在合成工作区里造）；② 域外脏文件 ⇒ **不命中**；③ **超宽 glob**（如 `src/**`、`**`）要**给分级**（拦 / 只提示 / 不提示）并**在报告里给出判定表**（按"宽到什么程度"给档），同时论证"**为什么不会回到当初收窄要避免的噪声**"；④ 未跟踪文件仍**不算**；⑤ 复用唯一出口、**无新增名单**；⑥ 反例各一（域内/域外）。
**验收**：**行为**（glob 域内命中 / 域外不命中 / 超宽分级 三态）+ **结构**（唯一出口）+ 判定表在报告里。

### 3.3 `DEF-088`（minor，**open**）—— `DEF-086` 的新守卫既不充分也不必要

**现象（V16 实测，三条都实证过）**：该守卫的判定只有一句"**行里同时出现 `理由记在|结论记在|详见` 与 `DEF-\d+`**" ⇒ ① **假阳性**：一条**完全合法**的引用（`git.ts` 写"本文件的归属结论记在 `DEF-054`（该缺陷在册且已修，**实体确实存在**）"）⇒ 守卫**红**；而没有 DEF 号的引用（"详见 `types.ts` 的 `isNeutralEvent`"）一律**放过** ⇒ 它证的只是"有没有写 DEF 号"。② **语言相关**：**英文**悬空引用 ⇒ **绿**（漏判）—— 与"语言无关"长期约束相抵。③ **只认证词**：**保留措辞、抽掉真正的结论** ⇒ 仍**绿**。
**修法（按 V16 建议的二态口径，具体机制由你设计并在报告里说明）**：判据要回答"**被引用的实体是不是真的承载该结论**"，而**不是**"这句话长什么样"。**必须避开**关键词匹配与语言依赖。
**DoD**：① **合法引用不许红**（**中英文各一格**：一条带 DEF 号且实体真的存在、一条指向代码里的真实定义）；② **悬空引用必须红**（**中英文各一格**）；③ **保留措辞而掏空语义必须红**（把结论句替换成空话，引用措辞不动）；④ 报告里给出机制说明 + **为什么它不是关键词匹配**；⑤ `DEF-086` 原缺陷的既有读数不被破坏（R17 留痕自足、与 `DEF-054` 的分界、`M182-02` 的既有反例）。
**验收**：**行为**（① 两格绿 / ②③ 各两格红）+ 机制说明。

### 3.4 `DEF-087`（minor，**open**）—— 同步口径要以 `package.json#files` 为准，并**双向核**

**现象**：实例副本里残留着一棵**不属于这个包**的陈旧 `docs/` 树（`package.json` 的 `files` = `['lib/src','client.js','client.d.ts','presets','skills','src/data','README.md','LICENSE','CHANGELOG.md']` —— **`docs/` 不在其中**）；其 `README.md` 只有 55 行、**没有 D1 节**。⇒ 从"已安装的包"读文档的人会读到**陈旧内容**，而与已同步的 `skills/` 形成**一面新一面旧**的分裂。**批次的同步口径本身没错**（它只承诺 `lib/src` + `src/data` + `skills`，实测 diff 全 0）。
**修法（落成机械面，别只写纪律）**：① 做一份**从 `package.json#files` 推导同步面**的 helper/脚本（**唯一来源是 `files`**，不许再手抄一份面清单）；② 它要能**报出副本里"多出来的面"**（不在 `files` 里的目录/文件），并**只报告不擅自删**（删除由驾驶舱决定）；③ **守卫**：断言"同步面清单 == `package.json#files`（去掉不需要同步的项并说明）"，并用**临时目录夹具**单测"多出来的面会被报出"（**不要在单测里碰真实实例路径** —— 那是环境相关的）。
**DoD**：① 同步面**由 `files` 推导**（给出推导命令与结果；若某些项明确不同步，逐条说明理由）；② 夹具单测：造一个含"多余面"的临时目录 ⇒ **报出该面**；③ 真实例的清理**由驾驶舱做**（你写不到工作区外，也不该写）—— 你只需让脚本/守卫就位并把"现盘会报出 `docs/`"作为**只读观测**写进报告；④ 不引入环境依赖（路径参数化）。
**验收**：**结构**（唯一来源 + 推导）+ **行为**（夹具三态：齐备 / 少一面 / 多一面）。

### 3.5 `R19`（判据自证，minor）—— **文字类判据的语言无关自证**

**背景**：本项目长期约束是**语言无关**，但本季它**三次以新形态复发**：`DEF-084`（中文路径因 `core.quotePath` 转义而永不匹配）、`DEF-088` 的②（**英文**悬空引用漏判）、以及更早的裁决。每次都是"判据读**自然语言文本**才能判定"造成的。
**修法（两半）**：
- **① 判据侧的自证要求**：凡判据/守卫需要**读自然语言文本**（注释、文档段落、描述、消息）才能判定时，**必须自带同一语义的两种书写形态**（一种 CJK、一种 ASCII/英文），并断言**判定结果一致**；在报告里逐条列出"本批哪些判据属于这一类、各自的自证格在哪"。
- **② 现盘清单**：至少把 `M182-02`（悬空引用）纳入；并**扫一遍**其它"读文本判定"的守卫（例如按关键词/措辞断言的判据），列出**清单 + 每一格补在哪**；对**只读语言包标签**（`t()` 取的文案）或**只读结构化字段**的判据**明确豁免**并说明理由。
**DoD**：① 给出**清单**（判据 / 属于"读自然语言文本"吗 / 自证格在哪 / 或为什么豁免）；② 至少 `M182-02` 的中英文两格**实测判定一致**（与 §3.3 的 DoD① ② 合起来做，别重复造）；③ **不许**为了过这一格而把判据改成"只认中文"或"只认英文"；④ 口径本身要**语言无关**（不写死任何语言/字符集）。

### 9.5 复验方法论（进下一批 §7 与角色卡）

1. **副本树复制清单**见 §9.3-3（含 `docs` 与 `node_modules` 软链）。
2. **变异自证要再加一条"脚本跑完了"的证据**：V19 有一次嵌套模板 `SyntaxError` 让脚本**根本没跑**，那一轮 4 个读数全是**上一轮遗留变异体**的旧读数 —— 靠"**PAD=0 竟然绿**"这种反直觉结果才抓回来（`patch()` 能自证"字节变了"，**证不了"脚本跑完了"**）。
3. **纯度采样在并发仓里要"同一时刻连采两次互核"**：V19 的 `lib` 整树 sha 开工/收尾不同值，它只担保**收尾态**（无新 mtime、两份独立副本 `diff` 0、1102 文件三方一致、sha 三次可复算）⇒ **`newermt` 只证"被碰过"，"没变"要靠整树 sha + `cmp`**（收口会话也遇到 `find lib -newermt` = 1 而内容未变，正是这条的实例）。
4. **`diff -rq` 的中文标签会骗出假 0**：按 `differ$`/`Only in` grep 计数会得 0 而总数 39（自相矛盾）⇒ **数行数，不要 grep 标签**。
5. **报告必须是 `.sdo/` 里的文件**：V20 的会话在收尾崩了，但报告在盘上 ⇒ **全部工作可救**（这条纪律本轮当场兑现价值）。
6. **收口与抽验分离**：owner 会话失败时，驾驶舱**释放**卡、由新会话**先独立抽验关键读数**再 `done`（**不代签**）—— 本轮 `TASK-137` 即如此收口：**逐格复算 0 处不一致**。
