## 1 病：本地绿 ≠ CI 绿，因为两者不是同一个世界

CI（`.github/workflows/ci.yml`）跑的是 `npm ci` → `npm run typecheck` → `npm test`，而 **`.sdo/` 在 `.gitignore` 里**（第 30 行）⇒ CI 的检出里**根本没有项目台账**。

我在本地用同样的干净检出模拟（`git archive HEAD | tar -x -C sim`，无 `.sdo`）：

```
npx tsc -p tsconfig.json          ⇒ exit 0
node scripts/run-tests.mjs        ⇒ 1529 tests / 1521 pass / 8 fail
```

8 条红里有 **7 条是「读真账」的守卫**（第 8 条是死链，另案）：

| # | 守卫 | 它读真账做什么 |
|---|---|---|
| 1 | `M108-08`（`TC-143`） | 真账里那些散文声明**不再判红** |
| 2 | `M149-06`（`TC-135`） | 真账存量「`requires` 非空」仍为 0 |
| 3 | `M151-07`（`TC-147`） | 真账里的评审文件逐字节不变 |
| 4 | `M169-07`（`TC-121`） | `.sdo` 存量 yml 全部读回 0 失败 |
| 5 | `M170-05`（`TC-130`） | 真账 18 条存量读侧不抛错 |
| 6 | `M172-05`（`TC-125`） | 真账评审全部带会话 uuid |
| 7 | `M207-02`（`DEF-029`） | **项目**台账三路读数逐字不变 |

**为什么这是本轮引入的**：1–6 是本轮补测批次新加的「真账读数」断言，7 是我加的 A1 守卫 —— 它们**都在有 `.sdo/` 的树里量过绿**，没人量过干净检出。这是"验证环境与被验证环境不同"的经典漏，记 `DEF-153`。

## 2 修法：缺真账就**明确 skip**，不许改夹具、不许删断言

### 2.1 一处判定，七处复用

在 `test/` 下加**一个**共享常量/函数（新建 `test/realLedger.ts`，或落在已有 `test/support/` 里）：

```ts
/** 本仓 `.sdo/` 不入库（.gitignore:30）⇒ 干净检出（CI）里没有真账可断言。 */
export const REAL_LEDGER_DIR = join(fileURLToPath(new URL('../../', import.meta.url)), '.sdo')
export function realLedgerSkip(): { skip: string } | undefined {
  if (existsSync(join(REAL_LEDGER_DIR, 'journal.jsonl'))) return undefined
  return {
    skip: '本仓 .sdo/ 不入库（.gitignore）⇒ 干净检出里没有真账；本守卫断言的是**真账的不变性**，无对象可断言（本地有 .sdo 时照常执行）',
  }
}
```

每一处改成（**只加 skip 选项，断言一个字都不删**）：

```ts
test('M207-02 动态（性质断言）：真跑一次缺陷追溯判据，项目台账三路读数逐字不变', realLedgerSkip() ?? {}, () => {
```

**七处全部照此办理**，不许散写七份 `existsSync` 判断（`DEF-044` 的教训：同一概念两处判据必然分叉）。

### 2.2 加一张网：防止下一个人再写一条 CI 杀手

新建 `test/m211.test.ts`（一格，**静态性质断言**）：扫描 `test/*.test.ts`，凡是**读取仓库自身 `.sdo/`**（`REAL_LEDGER` / `join(ROOT, '.sdo')` / `realLedgerSkip` 之外的裸读）的测试文件，必须 import 并使用 `realLedgerSkip()`；否则判红并点名 `文件:行`。

性质写成「**任何**以真账为夹具的守卫都必须声明缺账时的行为」，不要枚举这 7 个文件（枚举式 DoD 是 `REV-069` 判过的缺陷模式）。

## 3 禁区

1. **不许把真账断言改成夹具断言**。「存量零迁移 / 真账读侧不抛错 / 真账三路读数不变」只有在**真账**上才有意义；换成夹具就是把断言降级成同义反复（`DEF-149` 那族自欺）。
2. **不许删断言、不许把红改绿靠注释**。
3. **不许改 `.gitignore` 把 `.sdo/` 入库** —— 那是整本台账（含 journal 与真账 yml），不属于仓库。
4. **不许改 CI 配置**（例如 `continue-on-error`、只跑部分测试）来绕过 —— CI 红是对的，红的是我们的测试假设。
5. **skip 必须带理由**，且理由要说明"为什么无对象可断言"，不许写 `skip: true`。
