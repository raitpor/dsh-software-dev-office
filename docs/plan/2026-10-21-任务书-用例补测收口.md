### 0.3 为什么 PARTIAL 一律不记 pass（口径变化，明说）

前两轮我把 2 条「部分覆盖」的用例（`TC-084`、`TC-086`）记成了 `pass` 并把偏差写进 `evidence`。**本轮改了口径**：`pass` 的意思是「这条用例的 `expected` 成立」，而 `expected` 里只要有一句没被断言，这句话就只是**主张**，不是结论。32 条 PARTIAL 全部停在不记——它们不是"没查"，是"查了，还差断言"。

这也意味着：**不记不等于没问题**。§2 的 32 行就是欠账清单。

### 7.2 A3 不成立：设备节点判定改成「按 raw 字符串比」⇒ 带空白的设备路径漏过，且点名幽灵路径

**复现（我在 `lib` 上跑的，命令可照抄）**：

```bash
node -e "import('./lib/src/domain/writeScope.js').then(({evaluateWriteScope:f})=>{
  const b={role:'dispatched',tool:'edit',workspace:'/ws',workspaceRoot:'/ws',guardedTools:['edit'],sharedPaths:['.sdo/'],cardScopes:['src/a.ts']};
  for (const p of ['/dev/null',' /dev/null','/dev/null ','\t/dev/stdout']) { const d=f({...b,paths:[p]}); console.log(JSON.stringify(p),'=>',d.kind,d.code??'',JSON.stringify(d.violations)); }
})"
```

读数：

```
"/dev/null"     => allow  []
" /dev/null"    => deny write-scope-violation ["dev/null"]     ← 旧行为 allow
"/dev/null "    => deny write-scope-violation ["dev/null"]     ← 旧行为 allow
"\t/dev/stdout" => deny write-scope-violation ["dev/stdout"]   ← 旧行为 allow
```

**为什么**：`classifyTarget` 返回的 device 记录里存的是 **trim 过**的 `text`（`src/domain/scopePaths.ts:202-204`），而过滤器拿 `input.paths` 的**原始串**去比：

```ts
const deviceTargets = new Set(classified.filter((item) => item.kind === 'device').map((item) => (item.kind === 'device' ? item.raw : '')))
const candidates = (input.paths ?? []).filter((path) => !deviceTargets.has(path))   // ← 原始串 vs trim 过
```

旧实现 `isDevicePath(path)` 内部会 trim（委托 `isDeviceNode`），所以带空白的设备路径**当时是被摘掉的**。于是：**① 任务书要求的「行为必须一字不变」没达成，也没声明；② 拒因点名 `dev/null` 这个工作区里不存在的幽灵相对路径 —— `DEF-074` 那一族假阳性又从后门回来了。**

**修法（一行，按数组下标对位，不要拿 raw 当身份键）**：

```ts
const candidates = (input.paths ?? []).filter((_path, index) => classified[index]?.kind !== 'device')
```

**配套要补的测试（`test/m124.test.ts` 的 `M124-12` 后面加一格）**：

- `evaluateWriteScope` 对 `['/dev/null', ' /dev/null', '/dev/null ', '\t/dev/stdout']` **逐个** ⇒ `kind === 'allow'`（空白不许改变设备节点的结论）；
- 反例：同样带空白的**真越界**路径（如 `' /tmp/x'`）⇒ 仍 `deny write-scope-outside-workspace`，且 `violations` 里是**原始绝对路径** `/tmp/x`，**不是** `tmp/x`（这条同时钉住 DEF-074 的幽灵路径面）；
- 变异自证：把过滤改回 `deviceTargets.has(path)` ⇒ 新断言必须红；改回全绿且 harness 指纹与红跑相同。
