## 2 0.1.7：主题 = **台账可信化底座**

> 一句话：**让"写下来的东西"开始被守，让"没守的东西"无处躲，让台账本身成为可入库、可回滚、可版本化的资产。**
> 选它的理由：U1/U2/U3/U4 四件事都在改**所有后续工作的成本结构**；不先做，后面每次发版都要像 0.1.6 那样**手写缺口清单**糊过去。

### 批 1（数据模型）—— 版本作用域 `U4`

- 字段：`defects/tasks/risks/changes/issues` 补 `targetVersion / deferredTo / deferReason / deferApprovedBy`；`requirements` 另加 `targetVersion`（**不复用**现有 `version`，那是架构轮次 `0.1/0.2/0.3`）。
- 判据：**`C-71` 版本作用域闭合** + **`C-72` 缺口清单与台账恰好相等**。
- 回填：155 缺陷 + 169 卡按 ★裁定① 处理。
- **交付物**：字段 + 两条判据 + 回填脚本 + `CHANGELOG` 缺口清单改为**从台账生成**（不再手写）。
- **DoD**：故意给一条缺陷写 `deferredTo: 0.1.9` 而 CHANGELOG 不点名 ⇒ `C-72` 必红；反过来只写 CHANGELOG 不写字段 ⇒ 也必红。

### 批 2（判据）—— 声明—判据覆盖 `U1`

- 元判据 **`C-70`**：声明必须"有机判器"或"显式豁免"，否则进「未设防清单」并计数点名。
- 用它**当场点名**已知的 14 条 A 族，并清掉其中 6 条最可能假绿的：`DEF-105`（`REQ-060` 零判据）、`DEF-115`（幽灵用例端点）、`DEF-126`（`C-50` 只 skip 不红）、`DEF-149`（登记≠验证）、`DEF-135`（AC 无实现）、`DEF-106`（契约无守）。
- **DoD**：`REQ-060` 这类"零判据 must 需求"被 `C-70` 当场点名；清掉的 6 条各有**反例**（改回去必红）。

### 批 3（载体）—— 台账轻量 git `U2`

- `.sdo/` 自成 git repo（**不随主仓库**先跑起来）；每次 `sdo_*` 写入后自动 commit（消息含 `seq` + 事件类型）。
- 子代理在 `.sdo/worktrees/<task-id>/` 副本写，完成时 rebase 回主台账；`journal.jsonl` 是 append-only 行流 ⇒ 两边各追加不同行可自动合并。
- 派生视图（`project.json` 等）标 generated，不入库或不参与合并。
- **顺带解决**：`DEF-131`（`--write` 写坏源文件→`git checkout` 可回滚）、`DEF-127` 的台账层同类、`DEF-128`（写范围占用可由 worktree 独占表达）。
- **DoD**：两个会话同时写不同卡 ⇒ 零冲突且都留痕；写坏一次能被一条命令回滚；`git log` 能还原某个 `seq` 的台账全貌。

### 批 4（资产化）—— 脱敏 + 减重 + 入库 `U3` + `M2`

- 写入侧：落进台账的路径一律**相对路径**（`DEF-155` 规则的自然延伸）；会话 id 保留、主机名/用户目录不写。
- 一次性清洗：252 个真源文件 + 241 条 journal 事件 —— **需要一条 ADR**（"脱敏是唯一允许的历史改写，必须留前后哈希"），因为它与"历史不重写"冲突。
- 减重：`evidence/` 只留 `report.md` + 必要输入输出（748 MB → 目标 <50 MB）；`drafts/`、`handover/`、`project.json` 不入库。
- 入库边界：**真源层 8.2 MB 进主仓库**，`evidence/` 先不进（待减重达标后再议）。
- **DoD**：`grep -r "/home/" .sdo` 在真源层为 0；`.sdo` 入库后仓库增量 <10 MB；`sdo_scrub` 留下前后哈希与批准人。

## 5 每个版本的**退出条件**（统一口径，取代"全绿"幻想）

一个版本可以发，当且仅当：

1. **作用域内**（`targetVersion <= 当前` 且未被 `deferredTo` 放行）的 blocker/major 缺陷、`must` 需求、契约**全部闭合**（`C-71`）；
2. 作用域外的遗留项**每一条**都有 `deferredTo` + 理由 + 批准人；
3. `CHANGELOG` 本版「已知缺口」与 `deferredTo === 当前版本` 的集合**恰好相等**（`C-72`）；
4. 声明—判据覆盖（`C-70`）的「未设防清单」**只减不增**；
5. CI 在 ubuntu + windows × node 20/22 四格**全绿**（0.1.6 的 `DEF-153` 教训：本地绿不算）；
6. 交付清单存在且绑定产物哈希（`C-60` / `C-delivery-bound`）。
