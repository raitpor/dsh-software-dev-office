# 无工具降级清单

装不了插件时，SDO 的每个能力都换成“文件 + 命令 + 人”。下表是**唯一允许的映射**，其余能力一律不做。

| 能力 | 插件版 | 本 skill | 失去什么 |
|---|---|---|---|
| 追加写入 | `append(db, events)` 唯一入口 + 物化对账 | 追加式 Markdown（卡/台账/签字/读数） | 无事务、无唯一约束；靠人守“只追加” |
| 查询 | `query(db, {view}, {session})` 权限投影 | `grep`/`rg` + 手写过滤 | 无权限裁剪；看到什么由仓库权限决定 |
| 对账 | `verify()` 重算哈希链与投影 | `git` 历史 + `sha256sum` + 三条对账命令（`references/01`） | 抓不到“同一人改历史文件” |
| 门禁 | `judgeStage` 判定 + 事件 | 勾选表 + 命令证据 + 人签 | 没有强制，只能事后看证据 |
| 基线冻结 | `baseline` 行 + 两段式签字 | `01-计划.md` 的“冻结段” + 人签 | 无方向（收紧/放宽）机器判定 |
| 签字 | signerd 进程 + 加密密钥 + frontier | `ask_user_question` 三选项 + `sign/S*.md` | **无密码学签名、无防重放、无时间锚** |
| 派发/租约 | `lease`/`lock` 表 + 网关 | 卡面 `owner` + 书面交接 | 无锁：两人同时改同一文件靠 git 冲突 |
| 工作副本 | 内嵌 git 工作副本 + 快照 diff | 分支 + 小步提交 | 无写域机器判定（`write_scope` 只是声明） |
| 读数 | `readings:*` 脚本 + 生成物 | 同样跑脚本，或人工命令 + 输出摘要 | 无自动两遍一致比对（要人跑两次） |
| 权限 | `right`/`scope` 表 + 按 kind 判权 | 仓库权限 + 评审 | 无最小权限、无越权拦截 |

## 使用规则

1. 降级点必须写进签字文件的「已知边界」——**不许省略**。
2. 不得为了“看起来等价”而伪造：不写“已验证签名”，写“人签（问答选项，无密码学）”。
3. 能装插件后，按 `references/08` 迁回；先把文本账本当“导入源”，再逐条补事件。
