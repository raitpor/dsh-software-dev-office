# 真源与账本

## 1. 什么算真源

这里没有数据库，**文件就是真源**。四类对象各有唯一载体：

| 对象 | 载体 | 谁写 | 追加还是覆盖 |
|---|---|---|---|
| 意图 / 计划 / 签字 | `.sdo/00-意图.md`、`.sdo/01-计划.md`、`.sdo/sign/S*.md` | 人签过才生效 | 签字文件只追加新文件，不改旧文件 |
| 卡（工作单元） | `.sdo/cards/<卡号>.md` | 开卡人 | 卡内分节追加（评审、证据），不改历史判定 |
| 偏差 | `.sdo/台账.md` | 任何人发现即记 | **只追加行**；更正用新行 + `superseded` |
| 读数 | `.sdo/readings/<M>.md` | 里程碑收口人 | 每次取证追加一节，标时间与树 |

## 2. append-only 怎么写

- 任何“已经签过/已经判过”的内容**不改**：新事实写成新行/新节，注明取代关系。
- 需要更正时：旧行状态改 `superseded by D-xxx`？**不行**——状态列也只能追加新行，旧行保持原样。
- 每行带 `at`（ISO8601 含时区），禁止只写日期。

## 3. id 规则

| 前缀 | 用途 | 例 |
|---|---|---|
| `S<n>` | 人签记录 | `S3` |
| `D-<n>` | 偏差台账 | `D-12` |
| `C<n>` | 卡内判据 | `C4` |
| `M<n>` | 里程碑 | `M1` |
| 卡号 | 里程碑-序号 | `M2-3` |

id 单调递增，**不复用**、不回收；作废的 id 留空并写原因。

## 4. 对账（代替 verify）

收卡/收门前跑三条：

```bash
# ① 每次判定引用的 id 都存在
grep -o 'C[0-9]\+' .sdo/cards/M2-3.md | sort -u
# ② 签字指向的对象还在
git cat-file -e <commit> && echo ok
sha256sum <被签文件>
# ③ 台账表内不能有空行（在本项目根目录运行；子目录里先 cd 回根）；空行之后又出现 | 行 ⇒ 游离行，exit 1
node -e "const fs=require('fs');const L=fs.readFileSync('.sdo/台账.md','utf8').split('\n');let seen=false,blank=false,bad=[];L.forEach((l,i)=>{const t=l.trim();if(t.startsWith('|')){if(seen&&blank)bad.push(i+1);seen=true;blank=false;}else if(t===''){if(seen)blank=true;}else{seen=false;blank=false;}});if(bad.length){console.error('游离表格行：',bad.join(','));process.exit(1)};console.log('ok')"
```

第三条最省事的做法：**表内不留空行**；每批追加完跑一次“`|` 开头的行是否都在表头下”的检查。

## 5. 脱敏

不写：会话 id、用户名、`/home/...`、主机名/IP/端口、工具调用次数。写“某会话”“本机”即可。
