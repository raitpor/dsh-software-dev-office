# sdo-flow（skill 分支）

这个仓库在本分支上**只有流程 skill，没有插件代码**。

## 它是什么

把 SDO 的项目管理流程做成可携带的 skill：意图 → 计划评审 → 卡 → 两轮评审 → 人签 → 读数门 → 偏差台账。
**无插件、无数据库、无 `sdo_*` 工具**也能用：文件即真源，Markdown 账本代替事件表，`ask_user_question` 选项代替签名，可复跑命令代替机器门禁。

## 怎么用

1. 把这个仓库的 `.dsh/skills/sdo-flow/` 拷到目标仓库的 `.dsh/skills/`（或用 preset 安装后直接用它）。
2. 新建会话，模型会自动看到 `sdo-flow` skill；让模型加载它。
3. 从 `templates/` 拷出 `00-意图.md` / `01-计划.md` / 卡与台账模板，开始七步循环。

## 目录

```
.dsh/skills/sdo-flow/
  SKILL.md            入口：何时用/边界/目录约定/七步/人签协议/自检
  references/01…08    按需加载的细节（真源、判据、签字评审、计划卡、读数、台账、降级表、移植）
  presets/            瀑布 / 快速原型 / 增量：阶段序列 + 出口判据表 + 等价 policy
  templates/          七份可直接拷贝的模板
sdo/                  本仓库自己用这套流程时的产物（意图/计划/卡/台账/签字/读数）
```

## 已知边界

- 流程 preset 是**方法论层面的阶段预设**，不是宿主的 agent preset；本分支不装任何插件。
- 人签是问答选项，**不是密码学签名**；同一 uid 可改文件。
- 账本可改，审计靠 git 历史，不防篡改。
- 门禁靠人按清单判读，没有 `judgeStage` 那种机器强制。
